# Расширенные сетевые возможности (больше игроков, точность, разделение экрана)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Сетевые протоколы и мультиплеер](./README.md)

## Что это даёт геймдизайнеру

Помимо базовой совместимости с классическими протоколами, движок снимает многие их старые ограничения. Например, классический QuakeWorld был жёстко ограничен небольшим числом слотов и грубой точностью передачи координат — этот движок умеет расширять протокол на лету, договариваясь с современными клиентами о более богатых возможностях: больше игроков одновременно, точнее передаваемые координаты и углы обзора, поддержка нескольких локальных игроков за одним экраном (разделённый экран) на одной приставке/компьютере.

## Интерфейс настройки

- **[`maxclients`](../38-cvars-reference/04-network-server-cvars.md#maxclients)** — серверная переменная, задающая предельное число одновременно подключённых игроков (по умолчанию 8, но современные расширения протокола позволяют поднимать значение значительно выше классического лимита).
- **`cl_splitscreen`** — клиентская переменная, включающая локальный разделённый экран для дополнительных игроков за одной клавиатурой/геймпадами: `0` — выключено, `1` — на двоих, `2` — на троих, `4` — на четверых. Значение можно менять прямо во время игры, добавляя или убирая локальных игроков на лету. Работает для Quake, Hexen II и Quake II — в Quake III не поддерживается.
- **`allow_splitscreen`** — серверная переменная, которую нужно включить (`1`) на отдельном/выделенном сервере, чтобы разрешить подключение игроков с разделённым экраном (при игре «на своём же компьютере в одиночку» отдельно включать не требуется — сервер сам переходит в кооперативный режим вместо одиночного).
- **[`sv_bigcoords`](../38-cvars-reference/04-network-server-cvars.md#sv_bigcoords)** (см. также [«Совместимость с протоколами классических игр»](./classic-protocol-compatibility.md)) — расширяет точность передачи позиций и углов сверх классических ограничений.

## Примеры

- Для локального кооперативного вечера вчетвером на одном экране игрок выставляет `cl_splitscreen 4` — сразу же появляются три дополнительных локальных игрока, управляемых со своих геймпадов.
- Организатор LAN-турнира по кооперативному прохождению заранее включает `allow_splitscreen 1` на выделенном сервере, чтобы команды могли играть по двое-трое с одного компьютера.
