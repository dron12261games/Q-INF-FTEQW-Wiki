# Голосовой чат по сети

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Сетевые протоколы и мультиплеер](./README.md)

## Что это даёт геймдизайнеру

Движок умеет передавать голос игроков прямо по игровому сетевому соединению — без установки сторонних программ вроде отдельных голосовых чатов. Это удобно для командных режимов, кооператива или просто для живого общения в лобби, и всё настраивается прямо в игре: выбор микрофона, громкость собеседников, режим активации голоса (по нажатию клавиши, по громкости голоса или постоянно).

## Интерфейс настройки

Голос включается клиентской переменной **[`cl_voip_send`](../38-cvars-reference/03-audio-cvars.md#cl_voip_send)**:

- `0` — голос передаётся, только пока зажата клавиша, привязанная к команде **`+voip`**;
- `1` — голосовая активация (передача начинается автоматически при превышении порога громкости, заданного [`cl_voip_vad_threshhold`](../38-cvars-reference/03-audio-cvars.md#cl_voip_vad_threshhold) — по умолчанию `15`, и продолжается ещё [`cl_voip_vad_delay`](../38-cvars-reference/03-audio-cvars.md#cl_voip_vad_delay) секунд после того, как голос затих);
- `2` — постоянная передача (открытый микрофон);
- **`+4`** (добавляется к любому из вышеперечисленных режимов) — специальный битовый флаг: голос не отправляется в саму игру, а используется только для отдельных RTP-сессий (например, для внутренней голосовой конференц-связи вне игрового протокола).

Дополнительные полезные переменные:

- **[`cl_voip_capturedevice`](../38-cvars-reference/03-audio-cvars.md#cl_voip_capturedevice)** — выбор конкретного устройства записи (микрофона), если их несколько;
- **`cl_voip_micamp`** — усиление сигнала с микрофона;
- **`cl_voip_noisefilter`** и **`cl_voip_autogain`** — фильтр шума и автоматическая нормализация уровня голоса;
- **`cl_voip_codec`** — выбор кодека сжатия голоса, задаётся числом: `0` — Speex на 11 кГц, `1` — несжатый PCM, `2` — Opus, `3` — Speex на 8 кГц, `4` — Speex на 16 кГц, `5` — Speex на 32 кГц, `6` — PCM A-law (телефонный стандарт), `7` — PCM μ-law; по умолчанию переменная оставлена пустой, то есть движок использует свой обычный выбор кодека для текущей сборки;
- **`cl_voip_play`** — громкость воспроизведения чужих голосов (0 — выключить приём голоса совсем);
- **`cl_voip_ducking`** — во сколько раз приглушать звуки игры, пока кто-то говорит, чтобы речь было лучше слышно;
- **`cl_voip_showmeter`** — показывает индикатор уровня своего голоса поверх игрового интерфейса;
- **[`cl_voip_test`](../38-cvars-reference/03-audio-cvars.md#cl_voip_test)** — тестовый режим, позволяющий услышать свой голос напрямую, в обход сервера, чтобы проверить настройки микрофона без задержки сети.

## Примеры

- Игрок настраивает `cl_voip_send 1` (голосовая активация) и привязывает резервную клавишу на `+voip` для случаев, когда автоматическая активация срабатывает слишком чувствительно.
- Автор командного мода рекомендует игрокам выставить `cl_voip_codec 2` (Opus) для лучшего качества голоса при достаточной скорости интернета.
