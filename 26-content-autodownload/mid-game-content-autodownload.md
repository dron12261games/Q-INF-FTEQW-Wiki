# Автодокачивание недостающего контента прямо во время игры

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Загрузка контента из интернета](./README.md)

## Что это даёт геймдизайнеру

Если игрок подключается к серверу, использующему карту, модель или другой ресурс, которого нет на его компьютере, движок способен автоматически скачать недостающий файл — прямо во время подключения, без каких-либо действий со стороны игрока и без необходимости объяснять ему, что и откуда скачивать вручную. Это особенно важно для серверов с часто меняющимся или объёмным пользовательским контентом (нестандартные карты, модели, дополнения), где иначе каждому новому игроку пришлось бы отдельно и вручную устанавливать нужные файлы перед тем, как зайти в игру.

## Интерфейс настройки

На стороне игрока автодокачивание регулируется несколькими переменными:

| Переменная | Назначение |
|---|---|
| `cl_downloads` | полностью разрешает или запрещает любые автоматические докачивания (можно отключить из осторожности) |
| `cl_download_csprogs` | разрешает докачивание обновлённой клиентской игровой логики (см. [«Клиентская логика и интерфейс (CSQC)»](../16-quakec-scripting/client-side-quakec-csqc.md)), если сервер использует более новую версию, чем есть у игрока |
| `cl_download_packages` | управляет докачиванием целых пакетов контента, которые требует сервер: можно совсем не скачивать, скачивать и подключать временно на сеанс игры, либо скачивать и сохранять окончательно на будущее |
| `cl_download_wait` | решает, ждать ли полного завершения всех докачек перед входом в игру (безопаснее) или входить сразу же, пока файлы ещё докачиваются (может привести к временным подтормаживаниям) |
| `cl_download_mapsrc` | адрес-префикс отдельного веб-сервера, откуда предпочтительно скачивать именно карты (например, `http://example.com/path/gamemaps/`) — это позволяет разгрузить сам игровой сервер, отдавая крупные файлы карт через обычный быстрый веб-хостинг вместо игрового протокола |

Для сервера отдельной ручной настройки списка «что раздавать» обычно не требуется — сервер просто сообщает подключающемуся клиенту, какие ресурсы использует текущая карта/мод, а клиент дозагружает недостающее сам, при необходимости — из указанного адреса-источника, а не напрямую от игрового сервера, что заметно снижает нагрузку на сам сервер при большом числе одновременно подключающихся игроков.

### Тонкая настройка того, что сервер разрешает скачивать

Владелец сервера может явно ограничить, какие именно категории файлов разрешено раздавать по запросу клиентов — это важно как для защиты авторских прав, так и для банальной безопасности (случайная выдача файлов с паролями). Общий выключатель — **`allow_download`** (по умолчанию `1`; `0` полностью блокирует любую докачку с этого сервера, при этом можно сохранить возможность докачки через отдельный веб-хостинг переменной `sv_dlURL`). Более тонко раздача регулируется по типу содержимого:

| Переменная | По умолчанию | Что разрешает/блокирует |
| :--- | :--- | :--- |
| `allow_download_skins` | `1` | Файлы из папки `skins/`. |
| `allow_download_models` | `1` | Файлы из папок `progs/`/`models/`. |
| `allow_download_sounds` | `1` | Файлы из папки `sound/`. |
| `allow_download_particles` | `1` | Файлы из папки `particles/`. |
| `allow_download_demos` | `1` | Файлы из папки `demos/`. |
| `allow_download_maps` | `1` | Файлы из папки `maps/`, лежащие прямо на диске (не внутри архивов). |
| `allow_download_textures` | `1` | Файлы из папки `textures/`. |
| `allow_download_wads` | `1` | Файлы из папки `wads/` или файлы `.wad` в корне. |
| `allow_download_locs` | `1` | Файлы из папки `locs/` (файлы именованных точек карты). |
| `allow_download_packages` | `1` | Целые файлы архивов (`.pak`/`.pk3` и т.п.) с известным расширением. |
| `allow_download_refpackages` | `1` | Автоматическая докачка архивов, из которых при заходе на карту реально требуются какие-то файлы («связанные» пакеты) — команда `path` помечает такие архивы тегом `(ref)`. |
| `allow_download_root` | `0` | Разрешает докачку файлов прямо из корня игровой папки (не из специализированных подпапок) — по умолчанию запрещено. |
| `allow_download_pakmaps` | `0` | Разрешает докачивать файлы карт, если они лежат внутри архивов сервера, а не отдельными файлами: `0` — запрещено, `1` — разрешено, если архив не помечен как содержащий защищённый авторским правом контент, `2` — разрешено всегда (не рекомендуется). |
| `allow_download_pakcontents` | `0` | То же самое, но для остальных (не карт) файлов внутри архивов сервера. |
| `allow_download_copyrighted` | `0` | Разрешает докачку архивов, имя которых начинается с `pak` (по соглашению считающихся содержащими защищённый контент оригинальных игр) — трогать эту настройку стоит только если вы уверены в юридической чистоте раздаваемых файлов. |
| `allow_download_configs` | `0` | Разрешает докачку файлов `.cfg` или из папки `configs/` — **опасно**: конфиги могут содержать пароль RCON и другие приватные данные, включать не рекомендуется. |
| `allow_download_logs` | `0` | Разрешает докачку файлов с расширением `.log` — **опасно** по той же причине (могут содержать пароли и приватные данные игроков); задаётся только через командную строку или `rcon`, не через обычный конфиг. |
| `allow_download_other` | `0` | Разрешает докачку любых прочих файлов, не подпадающих ни под одну из категорий выше. |

## Примеры

- Сервер с еженедельно обновляемым набором пользовательских карт не требует от игроков вручную скачивать новые карты — при заходе на сервер с новой картой игрок автоматически получает недостающий файл и сразу попадает в игру.
- Владелец крупного проекта с большим объёмом карт настраивает `cl_download_mapsrc` на собственный быстрый файловый хостинг, чтобы игровой сервер отдавал только игровые данные, а увесистые файлы карт скачивались из более быстрого источника.
