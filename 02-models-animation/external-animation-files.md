# Внешние файлы анимаций (EXTERNALANIM)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Трёхмерные модели и анимация](./README.md)

## Объяснение на пальцах

Обычно геометрия модели и её анимация хранятся в одном файле. Но движок поддерживает специальный текстовый «файл-склейку» с расширением, характерным для формата MD5 (`.md5mesh`/`.md5anim` — см. [«Современные скелетные модели»](./skeletal-models-iqm-md5-dpm-zym.md)), который позволяет **собрать готовую модель из геометрии одного файла и анимации из другого (или даже из нескольких разных файлов)** — не пересобирая и не экспортируя модель заново. Это удобно, когда, например, одна и та же анимация бега должна использоваться сразу несколькими разными по форме персонажами, или когда аниматор и художник по геометрии работают независимо друг от друга и хотят объединить результаты своей работы без постоянного повторного экспорта.

## Синтаксис файла-склейки

Файл — это обычный текст, состоящий из строки-заголовка и последующих команд, каждая из которых занимает свою строку и состоит из ключевого слова и пути к отдельному файлу:

```
EXTERNALANIM

model test/imp.md5mesh

group test/idle1.md5anim
clampgroup test/attack1.md5anim
frames test/deathposes.md5anim
```

Обязательное правило: строка `model` должна идти сразу после заголовка `EXTERNALANIM` — она указывает, откуда брать саму геометрию (скелет и полигоны) итоговой модели. Все последующие строки добавляют анимационные группы поверх этой геометрии, причём порядковый номер, под которым каждая группа окажется доступна игровой логике (поле `frame`), определяется порядком её перечисления в файле сверху вниз.

## Пошаговый туториал

**Шаг 1.** Подготовьте файл геометрии в формате `.md5mesh` (скелет и полигональная сетка модели, без анимации).

**Шаг 2.** Подготовьте один или несколько файлов `.md5anim` с готовыми анимациями, совместимыми по структуре скелета с этой геометрией (одинаковое количество и иерархия костей).

**Шаг 3.** Создайте текстовый файл, например `mymonster.framegroups`, начинающийся со строки `EXTERNALANIM`.

**Шаг 4.** Сразу второй строкой добавьте `model путь/к/геометрии.md5mesh`.

**Шаг 5.** Ниже перечислите нужные анимации через `group`/`clampgroup`/`frames` (см. таблицу ниже).

**Шаг 6.** Сохраните файл и подключите его в игровой логике функцией `setmodel` точно так же, как обычную цельную модель — движок сам «сошьёт» указанные источники в единую модель во время загрузки.

## Практический пример: персонаж, собранный из переиспользуемых анимаций

```
EXTERNALANIM

model characters/guard.md5mesh

group anims/common/idle.md5anim
group anims/common/walk.md5anim
group anims/common/run.md5anim
clampgroup anims/guard/attack_melee.md5anim
clampgroup anims/common/death_backward.md5anim
frames anims/common/death_poses.md5anim
```

Построчный разбор: `model` подключает геометрию конкретного персонажа-охранника; три группы `group` (простой, ходьба, бег) помечены как зацикленные и будут бесперебойно повторяться, пока игровая логика держит соответствующий номер кадра активным; `clampgroup` для атаки и смерти вместо этого «застревает» на последнем кадре анимации по её окончании, а не начинает проигрывание заново — что и требуется для одноразовых действий; `frames` разбивает файл с набором статичных предсмертных поз на отдельные одиночные кадры, каждый из которых становится доступен как самостоятельная «анимация» из одного кадра.

## Инженерный справочник

| Ключевое слово | Аргумент | Дотошное описание поведения |
| :--- | :--- | :--- |
| `EXTERNALANIM` | нет (строка-заголовок) | Обязательная первая строка файла, идентифицирующая его как файл-склейку анимаций для загрузчика движка |
| `model` | строковый путь к файлу `.md5mesh` | Задаёт источник геометрии (скелета и полигональной сетки) итоговой модели; должен быть указан сразу после заголовка, до любых анимационных групп |
| `group` | строковый путь к файлу `.md5anim` | Добавляет очередную анимационную группу, зацикленную (loop) по умолчанию — после последнего кадра анимация начинается заново |
| `clampgroup` | строковый путь к файлу `.md5anim` | Добавляет анимационную группу, которая не зацикливается — по достижении последнего кадра проигрывание «застревает» на нём, а не начинается заново (подходит для одноразовых действий вроде смерти или удара) |
| `frames` | строковый путь к файлу `.md5anim` | Разбивает указанный файл анимации на отдельные одиночные кадры-позы, каждый из которых регистрируется как собственная «анимация» из одного кадра, с частотой проигрывания по умолчанию 24 кадра в секунду |
