# Параметры запуска игры

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Конфигурационные файлы и консоль](./README.md)

## Что это даёт геймдизайнеру

Помимо консоли и конфигурационных файлов, движку можно передать команды и переменные прямо в момент запуска — через параметры командной строки (то, что указывается в ярлыке игры или при запуске из терминала). Это удобно для автоматизации: например, чтобы сразу запустить конкретный мод, карту и режим игры одним щелчком по ярлыку, без захода в меню и ручной настройки.

## Интерфейс настройки

Параметры добавляются после имени исполняемого файла движка. Есть два вида «управляющих» параметров:

- **`+команда`** — выполнить консольную команду или установить переменную сразу при запуске;
- **`-параметр`** — специальный параметр самого движка (выбор игровых папок, режима окна и т.д.), не являющийся консольной командой.

```
fteqw +set sv_port 26000 +map dm4
```

Наиболее полезные `-параметры`:

| Параметр | Назначение |
|---|---|
| `-basedir <путь>` | указать корневую папку, где искать все игровые данные |
| `-basegame <папка>` | указать папку с данными основной игры |
| `-game <папка>` | указать папку мода, подключаемого поверх основной игры |
| `-manifest <файл.fmf>` | загрузить файл-манифест мода/игры вместо ручного набора параметров |
| `-window` | запустить в оконном, а не полноэкранном режиме |
| `-dedicated` | запустить движок только в роли сервера, без графики (для постоянно работающих серверов) |
| `-nohome` | не использовать домашнюю папку пользователя для конфигов/сохранений, писать рядом с движком |

Также существуют «игровые» флаги-подсказки, которые помогают движку точнее определить нужную игру в «людном» общем каталоге данных: `-quake`, `-quake2`, `-quake3`, `-hexen2`, `-halflife`, `-halflife2`.

### Дополнительные полезные `-параметры`

| Параметр | Назначение |
| :--- | :--- |
| `-width <N>` / `-height <N>` | задать стартовое разрешение экрана в пикселях (указание только `-width` подбирает высоту автоматически по стандартному соотношению сторон). |
| `-bpp <N>` | задать глубину цвета экрана в битах (актуально в основном для очень старых видеорежимов). |
| `-conwidth <N>` / `-conheight <N>` | задать отдельное разрешение для консоли и 2D-интерфейса, независимо от разрешения самого 3D-рендера. |
| `-zone <КБ>` | увеличить размер стартового блока памяти движка (`Zone`) для очень требовательных модов — на современных системах почти не требуется, память выделяется динамически. |
| `-particles <N>` | задать максимальное число одновременных классических частиц (актуально для программного рендерера/классической системы частиц). |
| `-nosound` | полностью отключить звуковую подсистему при запуске. |
| `-nomouse` | отключить обработку мыши движком (например, при отладке через удалённый рабочий стол). |
| `-noplugins` | не загружать при старте ни встроенные, ни внешние [плагины движка](../35-engine-plugins/README.md). |
| `-condebug` | вести подробный лог консоли в текстовый файл `qconsole.log` рядом с игрой, помимо вывода на экран. |
| `-nostdin` / `-nostdout` | не читать команды из стандартного ввода терминала / не дублировать консоль в стандартный вывод — полезно при запуске выделенного сервера как управляемой службы. |
| `-cheats` | разрешить чит-команды (`noclip`, `god`, `give` и т.п.) даже вне одиночной игры — обычно требуется явно для тестовых/приватных серверов. |
| `-readonly` | запретить движку любую запись на диск (конфиги, демозаписи, кэш) — полезно для запуска с носителя, доступного только для чтения. |
| `-unsafefopen` | отключить файловую песочницу для [`fopen`](../37-quakec-builtins-reference/06-files-database-builtins.md#fopen), разрешая читать/писать за пределами папки мода (см. [«Чтение и запись файлов из игровой логики»](../18-data-access-from-scripts/file-read-write-from-scripts.md)) — использовать только на полностью доверенных серверах. |
| `-allowfileuri` | разрешить схему `file:///` в файловых операциях игровой логики для доступа к произвольным путям диска. |
| `-noupdate` / `-noautoupdate` | отключить проверку и автоматическую загрузку обновлений самого движка при старте. |
| `-safe` / `-noenumerate` | запустить в «безопасном» режиме с упрощённым перебором звуковых/видеоустройств — помогает обойти проблемы с нестабильными драйверами при первом запуске. |
| `-homedir <путь>` / `-usehome` | задать собственную «домашнюю» папку для конфигов и сохранений вместо стандартной папки пользователя ОС. |
| `-svport <N>` (или `-port <N>`) | задать номер сетевого порта, который будет слушать сервер. |

## Примеры

- Ярлык для запуска сервера конкретного мода сразу на нужной карте с ограничением на 8 игроков и автоматическим анонсом в интернете:
  ```
  fteqw +set sv_public 2 +set sv_playerslots 8 +map dm4
  ```
- Запуск определённого мода поверх базовой игры:
  ```
  fteqw -game fortress
  ```
- Запуск полностью самостоятельной игры, никак не связанной с данными Quake:
  ```
  fteqw -basegame openquartz
  ```
