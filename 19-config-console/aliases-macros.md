# Алиасы и командные макросы

> [⬅ Предыдущая страница](cvars-engine-variables.md) | [Следующая страница ➡](startup-parameters.md)

> [⬅ Вернуться к оглавлению вики](../README.md)

## Что это даёт геймдизайнеру

**Алиас** — это пользовательская команда, которая при вызове выполняет сразу несколько других команд, объединённых под одним удобным именем. Это позволяет игроку (или самому моду, поставляемому с готовым набором алиасов) создавать сложные комбинации действий — например, «переключить оружие и одновременно сказать команде текстовое сообщение» — и вызывать их одной короткой командой или одной клавишей.

## Интерфейс настройки

Алиас создаётся командой [`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias), где вторым аргументом в кавычках передаётся список команд, разделённых точкой с запятой:

```
alias quad_and_taunt "impulse 255; say Activating quad damage!"
bind "q" "quad_and_taunt"
```

После этого ввод в консоли (или нажатие привязанной клавиши) `quad_and_taunt` выполнит сразу обе команды из списка. Команда без аргументов ([`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) в одиночку) выводит список всех определённых алиасов — то же самое делает и отдельная команда [`aliaslist`](../44-cli-commands-reference/05-filesystem-system-commands.md#aliaslist).

Есть важные правила приоритета имён при создании алиаса:
- Если имя уже занято обычной консольной командой движка (например, [`quit`](../44-cli-commands-reference/02-client-ui-commands.md#quit)), алиас с таким именем создать нельзя — команды движка всегда важнее алиасов. Движок автоматически предложит переименовать алиас, добавив суффикс `_a` (например, `quit_a`), либо откажет в создании, если суффикс тоже занят.
- Если имя совпадает с уже существующим cvar, по умолчанию алиас **может перекрыть** этот cvar при вводе по имени. Если это нежелательно, выставьте [`cl_aliasoverlap 0`](../38-cvars-reference/07-system-misc-cvars.md#cl_aliasoverlap) — тогда новый алиас будет переименован с суффиксом `_a`, а сам cvar по-прежнему останется доступен через [`set`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#set)/[`seta`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#seta).
- Имя [`say`](../44-cli-commands-reference/02-client-ui-commands.md#say) зарезервировано движком специально и не может быть переопределено алиасом — это защита от подмены команды чата вредоносными автоматическими действиями (например, читерскими модами).

### Аргументы внутри алиаса ($1, $2, $* и cvar-подстановки)

Алиасы поддерживают полноценную подстановку аргументов, с которыми был вызван сам алиас — это превращает алиас в настоящий параметризуемый макрос, а не просто список фиксированных команд:

- **`$0`** — раскрывается в имя, под которым был вызван сам алиас (полезно для написания «саморекурсивных» вспомогательных алиасов).
- **`$1`, `$2`, `$3`, ...** — раскрываются в соответствующий по номеру аргумент, с которым вызывался алиас (`$1` — первый аргумент и т.д.); отсутствующий аргумент раскрывается в пустую строку.
- **`${N-}`** (например, `${2-}`) — раскрывается сразу во «весь хвост» аргументов начиная с номера N и до конца строки вызова — удобно, когда нужно передать все оставшиеся слова целиком дальше (например, в [`say`](../44-cli-commands-reference/02-client-ui-commands.md#say)).
- **`${name_cvar}`** — подставляет текущее значение указанного cvar прямо в тело алиаса при каждом вызове (не при создании алиаса!) — то есть значение всегда актуальное на момент выполнения.
- **`${name_cvar q}`** — то же самое, но значение экранируется (кавычки внутри значения корректно экранируются, а пустое значение превращается в пустую строку) — полезно, если значение cvar может случайно содержать кавычки или спецсимволы, ломающие синтаксис команды.
- **`${name_cvar asis}`** — подставляет значение cvar буквально, без какого-либо экранирования.
- **`${name_cvar ?}`** — принудительно подставляет что-то даже для несуществующего cvar (пустую строку вместо ошибки).
- **`${name_cvar !}`** — подставляет значение, но прерывает выполнение строки с ошибкой, если такого cvar не существует — полезно для алиасов, которые обязаны получить конкретную настройку и не должны молча продолжать работу с пустым значением.

### Команда `wait` — пауза выполнения на один кадр

Внутри алиаса (и вообще в любой цепочке команд, разделённых `;`) можно использовать служебную команду **[`wait`](../44-cli-commands-reference/05-filesystem-system-commands.md#wait)** — она приостанавливает выполнение оставшихся команд строки ровно до следующего отрисованного кадра игры. Это классический приём для написания алиасов с задержкой между действиями без обращения к таймерам, например:

```
bind g "impulse 5; +attack; wait; -attack; impulse 2"
```

Здесь оружие переключается на пятый слот, кнопка атаки нажимается, через один кадр отпускается, а затем оружие переключается обратно — всё одним нажатием клавиши `g`.

### Прочие команды для работы с алиасами

| Команда/переменная | Синтаксис | Назначение |
| :--- | :--- | :--- |
| [`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) | [`alias <name> "<command1>; <command2>; ..."`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) | Создаёт или изменяет алиас с указанным именем. |
| [`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) (без аргументов) | [`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) | Выводит список всех текущих алиасов и их содержимое. |
| [`newalias`](../44-cli-commands-reference/05-filesystem-system-commands.md#newalias) | [`newalias <name> "<commands>"`](../44-cli-commands-reference/05-filesystem-system-commands.md#newalias) | Как [`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias), но регистрирует алиас, только если он ещё не существует — не трогает уже существующий одноимённый алиас. |
| [`aliaslist`](../44-cli-commands-reference/05-filesystem-system-commands.md#aliaslist) | [`aliaslist`](../44-cli-commands-reference/05-filesystem-system-commands.md#aliaslist) | Явно выводит список всех определённых алиасов (то же самое, что [`alias`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) без аргументов). |
| [`aliasedit`](../44-cli-commands-reference/05-filesystem-system-commands.md#aliasedit) | [`aliasedit <name>`](../44-cli-commands-reference/05-filesystem-system-commands.md#aliasedit) | Открывает содержимое существующего алиаса прямо в строке ввода консоли для редактирования (а не переписывает его целиком новым текстом). |
| [`cfg_save_aliases`](../38-cvars-reference/07-system-misc-cvars.md#cfg_save_aliases) | cvar, `0`/`1`, по умолчанию `1` | Определяет, сохраняются ли пользовательские алиасы в конфигурационный файл вместе с остальными настройками при выходе из игры. |
| [`cl_aliasoverlap`](../38-cvars-reference/07-system-misc-cvars.md#cl_aliasoverlap) | cvar, `0`/`1` | Разрешает или запрещает создание алиаса с именем, совпадающим с именем уже существующего cvar (по умолчанию такие алиасы автоматически переименовываются). |

Важный нюанс: алиасы, присланные игроку **сервером** (например, через механизм подсказок сервера при подключении), считаются временными и не сохраняются в конфиг игрока в [`cfg_save_aliases`](../38-cvars-reference/07-system-misc-cvars.md#cfg_save_aliases) — они действуют только в рамках текущего подключения к этому серверу и полностью забываются при отключении или смене карты.

## Командные макросы ($-переменные)

Помимо алиасов, движок поддерживает отдельную, независимую систему **макросов** — специальных переменных вида `$name`, которые при вводе в консоли или исполнении из конфигурационного файла заменяются на динамически вычисляемое значение прямо в момент выполнения строки (а не хранят фиксированный список команд, как алиас). Список всех доступных макросов выводится командой **[`macrolist`](../44-cli-commands-reference/05-filesystem-system-commands.md#macrolist)**.

Часть макросов относится к базовым служебным (доступны всегда), часть — к «командным макросам» ([teamplay](../38-cvars-reference/04-network-server-cvars.md#teamplay) macros, унаследованы от QuakeWorld-клиента ezQuake/ZQuake и предназначены для быстрого сообщения игровой информации команде через чат):

| Макрос | Категория | Что подставляет |
| :--- | :--- | :--- |
| `$[random](../37-quakec-builtins-reference/01-math-vector-builtins.md#random)` | Служебный | Случайное целое число. |
| `$time` | Служебный | Текущее время (часы:минуты). |
| `$date` | Служебный | Текущая дата в формате ДД.ММ.ГГГГ. |
| `$usdate` | Служебный | Текущая дата в американском формате ММ.ДД.ГГГГ. |
| `$ukdate` | Служебный | Текущая дата в британском формате (аналогично `$date`). |
| `$version` | Служебный | Версия и сборка движка. |
| `$qt` | Служебный | Символ кавычки — удобно для вставки кавычки внутрь строки, которая сама уже взята в кавычки. |
| `$dedicated` | Служебный | Признак того, запущен ли выделенный (dedicated) сервер. |
| `$gamedir` | Служебный | Имя текущей активной игровой директории (мода). |
| `$demoplayback` | Служебный | Признак того, идёт ли сейчас воспроизведение демо-записи. |
| `$connectiontype` | Служебный | Тип текущего сетевого подключения к серверу. |
| `$ping` / `$latency` | Игровой (командный) | Текущий пинг игрока до сервера. |
| `$health` | Игровой (командный) | Текущее здоровье игрока. |
| `$chealth` | Игровой (командный) | Здоровье, объединённое с показателем брони, в удобной для чата форме. |
| `$armor` / `$armortype` | Игровой (командный) | Текущее количество и тип брони игрока. |
| `$colored_armor` | Игровой (командный) | Значение брони, автоматически подсвеченное цветом чата в зависимости от типа. |
| `$shells` / `$nails` / `$rockets` / `$cells` | Игровой (командный) | Количество патронов каждого вида боеприпасов. |
| `$ammo` | Игровой (командный) | Количество патронов к текущему выбранному оружию. |
| `$weapon` / `$weaponnum` | Игровой (командный) | Название или номер текущего активного оружия. |
| `$weapons` | Игровой (командный) | Список всего оружия, которое подобрал игрок. |
| `$bestweapon` / `$bestammo` | Игровой (командный) | Название и боезапас самого мощного доступного оружия. |
| `$powerups` / `$colored_powerups` / `$colored_short_powerups` | Игровой (командный) | Список активных усилений игрока (квад, кольцо и т.п.), в разных вариантах форматирования. |
| `$droppedweapon` | Игровой (командный) | Оружие, которое игрок только что выронил после смерти. |
| `$team` | Игровой (командный) | Название команды игрока. |
| `$point` / `$pointloc` / `$pointatloc` | Игровой (командный) | Именованная точка на карте, куда сейчас смотрит игрок (при наличии файла точек карты, `.loc`). |
| `$deathloc` / `$lastloc` | Игровой (командный) | Место последней смерти игрока / последняя известная локация. |
| `$took` / `$tookloc` / `$tookatloc` | Игровой (командный) | Что и где подобрал игрок последним. |
| `$droploc` / `$droptime` | Игровой (командный) | Где и когда игрок в последний раз что-то выронил. |
| `$need` | Игровой (командный) | Список того, чего игроку сейчас не хватает (здоровья, брони, оружия). |
| `$matchname` / `$matchtype` / `$matchstatus` | Игровой (командный) | Название, тип и статус текущего проходящего матча (для турнирных серверов). |
| `$triggermatch` | Игровой (командный) | Информация о последнем сработавшем игровом триггере матча. |
| `$ledstatus` / `$ledpoint` | Игровой (командный) | Информация для индикаторов (LED) поддерживаемых периферийных устройств. |
| `$lastpowerup` | Игровой (командный) | Последнее замеченное игроком усиление на карте. |
| `$tf_skin` | Игровой (командный) | Текущий скин игрока в режиме Team Fortress. |

Часть «игровых» макросов помечена в движке как **«спорные» (disputable)** — то есть раскрывающих потенциально важную для честной игры информацию (например, здоровье или количество патронов противника при определённых условиях). Их работу можно полностью отключить переменной **[`tp_disputablemacros`](../38-cvars-reference/07-system-misc-cvars.md#tp_disputablemacros)** (по умолчанию `1` — разрешены); это даёт администраторам турниров возможность запретить автоматические подсказки, которые считаются «полу-читерскими» в честной соревновательной игре.

## Примеры

- Алиас-«макрос» для быстрого переключения набора настроек графики: [`alias fastgfx "seta [r_shadows](../38-cvars-reference/02-lighting-materials-cvars.md#r_shadows) 0; seta [r_bloom](../38-cvars-reference/02-lighting-materials-cvars.md#r_bloom) 0; echo Fast graphics enabled"`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias).
- Игровой мод поставляется с готовым алиасом `+voicemenu`, который открывает быстрое меню голосовых команд по нажатию одной клавиши.
- Параметризуемый алиас для отправки в чат произвольного текста с указанием текущего здоровья: [`alias hp_report "say Health: $health, armor: $armor - ${1-}"`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) — вызов `hp_report help me!` подставит в конец сообщения именно этот текст, а в начале — актуальные на момент вызова значения здоровья и брони.
- Алиас с задержкой для «дабл-джампа» через быстрое перепривязывание клавиши: [`alias quickswitch "impulse 1; wait; impulse 2"`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias) — переключение на первое оружие, пауза на кадр, и переключение обратно на второе.
- Спорный командный макрос `$need`, вызванный через [`alias sos "say [SOS] Need: $need"`](../44-cli-commands-reference/05-filesystem-system-commands.md#alias), при вводе `sos` в чат автоматически подставит список недостающих ресурсов игрока для остальной команды.
