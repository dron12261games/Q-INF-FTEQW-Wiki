## Что это даёт геймдизайнеру

**Cvar** (console variable, «консольная переменная») — это именованная настройка со значением, которую можно посмотреть и изменить через консоль или конфигурационный файл. Это основной универсальный «пульт управления» практически любым поведением движка и мода: от разрешения экрана и громкости звука до правил конкретной игры. Важно, что переменные заводит не только сам движок — **игровая логика мода (QuakeC) тоже может объявлять свои cvar**, обычно через `autocvar` или builtin [`registercvar`](../37-quakec-builtins-reference/12-system-debug-builtins.md#registercvar). По поведению они близки к встроенным, но у [`registercvar`](../37-quakec-builtins-reference/12-system-debug-builtins.md#registercvar) есть практический нюанс: если переменную пытаются задать раньше, чем код мода её зарегистрировал, стартовый конфиг всё равно должен использовать обычный [`set`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#set)/[`seta`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#seta).

## Интерфейс настройки

Базовый синтаксис в консоли или конфиг-файле:

```
var_name value      // самый короткий способ — движок сам поймёт, что это cvar
set var_name value  // явно временно изменить значение (до перезапуска движка)
seta var_name value // изменить значение и сразу пометить на сохранение в конфиг
```

Разница между [`set`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#set) и [`seta`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#seta) важна: значение, заданное через [`set`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#set), действует только до следующего перезапуска движка (или смены карты/мода), а [`seta`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#seta) дополнительно помечает переменную как подлежащую записи в конфигурационный файл при сохранении настроек ([`cfg_save`](../44-cli-commands-reference/05-filesystem-system-commands.md#cfg_save)), то есть значение переживёт перезапуск.

Посмотреть все существующие переменные и их текущие значения можно командой [`cvarlist`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvarlist), а найти описание конкретной переменной — введя в консоли её имя без значения (движок покажет справку, если она у переменной есть).

### Команда `cvarlist` — фильтры и ключи

[`cvarlist`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvarlist) принимает набор ключей, позволяющих быстро находить нужные переменные среди сотен зарегистрированных, а также имя (с поддержкой масок `*`/`?`) для поиска по подстроке имени:

| Ключ | Назначение |
| :--- | :--- |
| `-c` | Показывать только переменные, значение которых отличается от значения по умолчанию — удобно, чтобы быстро увидеть «всё, что игрок/мод изменил». |
| `-F` | Показывать флаги каждой переменной (архивная, только для чтения, серверная и т.д.). |
| `-L` | Показывать «отложенные» (latched) значения — те, что вступят в силу только после перезапуска карты/движка. |
| `-a` | Показывать альтернативные (устаревшие/совместимые) имена переменной, если они есть. |
| `-d` | Показывать значение переменной по умолчанию рядом с текущим. |
| `-f <flag>` | Показывать только переменные с указанным флагом (ключ можно указывать несколько раз для нескольких флагов). |
| `-g <group>` | Показывать переменные только из указанной группы (с поддержкой масок в названии группы). |
| `-l` | Показывать уровень ограничения доступа переменной (кто может её менять — обычный пользователь, только консоль, только сервер и т.п.). |
| `-r` | Убрать заголовки групп и списка — «сырой» вывод только именами и значениями. |
| `-v` | Показывать текущие значения переменных (обычно уже включено по умолчанию). |

Например, [`cvarlist -c *`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvarlist) покажет все переменные, значение которых на данный момент отличается от значения по умолчанию — очень удобно перед сохранением или публикацией собственного пресета настроек, чтобы убедиться, какие именно значения будут в нём переопределены.

### Дополнительные команды для работы со значениями

| Команда | Синтаксис | Назначение |
| :--- | :--- | :--- |
| [`toggle`](../44-cli-commands-reference/05-filesystem-system-commands.md#toggle) | [`toggle <name_cvar> [value1 [value2]]`](../44-cli-commands-reference/05-filesystem-system-commands.md#toggle) | Переключает переменную между двумя значениями при каждом вызове (без аргументов — переключает `0`/`1`, то есть работает как классический выключатель). |
| [`inc`](../44-cli-commands-reference/05-filesystem-system-commands.md#inc) | [`inc <name_cvar> [step]`](../44-cli-commands-reference/05-filesystem-system-commands.md#inc) | Прибавляет к текущему значению переменной указанное число (можно указать отрицательное число, чтобы уменьшить значение) — удобно для настройки, изменяемой пошагово по нажатию клавиши (например, громкости). |
| [`cvarreset`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvarreset) | [`cvarreset <name_cvar>`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvarreset) | Сбрасывает указанную переменную к её значению по умолчанию. |
| [`cvar_purgedefaults`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvar_purgedefaults) | [`cvar_purgedefaults`](../44-cli-commands-reference/05-filesystem-system-commands.md#cvar_purgedefaults) | Сбрасывает у всех переменных именно значение «по умолчанию» (не текущее значение!) обратно к исходному значению самого движка — используется внутренне при перезапуске, чтобы значения по умолчанию, заданные предыдущим модом/картой через `default.cfg`, не «утекали» в следующую игровую сессию. |

Некоторые переменные ведут себя по-особенному в зависимости от того, как их зарегистрировал движок или мод, например:
- переменная может быть доступна только для чтения (нельзя изменить из консоли вручную);
- переменная может автоматически передаваться серверу как часть данных об игроке (см. [«Ник, скин и командная принадлежность игрока (userinfo)»](../20-player-userinfo/player-userinfo-name-skin-team.md)) или, наоборот, серверу — клиентам;
- переменная может применяться только «с задержкой» — например, после смены карты или перезапуска графической подсистемы, если она относится к настройкам, которые нельзя поменять «на лету».

## Примеры

- [`seta vol "0.5"`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#seta) — установить и запомнить громкость звука на уровне 50%.
- [`set [sv_gravity](../38-cvars-reference/05-physics-gameplay-cvars.md#sv_gravity) "400"`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#set) — временно изменить силу гравитации в текущей игровой сессии (типичный пример переменной, которую заводит сама игровая логика мода, а не движок).
- Мод регистрирует собственную переменную `mymod_hardmode "0"`, которую игрок включает командой [`seta mymod_hardmode "1"`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#seta), — и логика мода на QuakeC читает это значение, меняя сложность игры.
