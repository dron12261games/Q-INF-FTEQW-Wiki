# Подключение TTF-шрифтов

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Шрифты и текст](./README.md)

## Что это даёт геймдизайнеру

Помимо классического растрового шрифта Quake, движок умеет отображать текст настоящими шрифтами формата TrueType (`.ttf`) — теми же, что используются в операционной системе и текстовых редакторах. Это даёт куда более чёткий, плавно масштабируемый и профессионально выглядящий текст интерфейса, особенно на высоких разрешениях экрана, а также возможность подобрать шрифт, точно соответствующий стилю игры (например, готический шрифт для фэнтезийного мода или строгий технический шрифт для научно-фантастического).

## Интерфейс настройки

Шрифт для консоли и текстовых элементов интерфейса задаётся переменной **`gl_font`** (для консоли) или **`con_textfont`** (общий текстовый шрифт интерфейса) — значением служит имя файла шрифта. Движок сначала ищет указанное имя как обычный игровой ресурс — то есть шрифт можно положить прямо внутрь `.pk3`/`.pak`-архива мода или в папку игры, при этом движок сам подставляет расширения `.ttf` и `.otf`, если они не указаны явно. Если файл с таким именем внутри игровых файлов не найден и в имени нет символа `/` (то есть это не похоже на путь), движок как запасной вариант обращается к системному каталогу шрифтов, установленных в операционной системе (на Windows — системная папка `Fonts`, на Linux со сборкой с `fontconfig` — через системный подбор шрифтов по имени семейства), и может подгрузить оттуда системный шрифт с таким названием.

Полный формат значения переменной устроен так:

```
основной_шрифт[,альт_шрифт[,...]][?парам1[&парам2[...]]][:вторичный_шрифт[,альт[...]][?парам...]]
```

То есть после имени шрифта через запятую можно перечислить дополнительные альтернативные начертания (используются как резерв для символов, отсутствующих в основном шрифте), через `?` — список параметров данного начертания, а через `:` — второй, отдельный шрифт, используемый для текста, выводимого с управляющим кодом полужирного/альтернативного стиля.

Например, значение `cour?col=1,1,1:couri?col=0,1,0` подключает шрифт Courier белого цвета как основной и курсивный вариант Courier зелёного цвета — как альтернативный, вызываемый переключением стиля текста прямо посреди строки.

Поскольку TTF-шрифты обычно крупнее классического пиксельного шрифта, при их использовании почти всегда требуется дополнительно увеличить масштаб текста консоли переменной [`vid_conautoscale`](../38-cvars-reference/01-video-rendering-cvars.md#vid_conautoscale) (рекомендуется значение `1.5` и выше) либо явно задать высоту консоли переменной [`vid_conheight`](../38-cvars-reference/01-video-rendering-cvars.md#vid_conheight).

## Инженерный справочник: параметры имени шрифта

| Параметр | Синтаксис | Описание | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `col=r,g,b` | Три числа 0.0–1.0 через запятую | Задаёт собственный цветовой оттенок шрифта, переопределяя обычный цвет текста игры; допустим только когда вторичное начертание не указано | цвет текста игры без изменений |
| `fmt=q` | Буква-код формата | Растровый шрифт в стиле Quake со стандартной кодовой страницей символов движка (не требует резервных символов для «странных» глифов) | — |
| `fmt=l` | Буква-код формата | Растровый шрифт в стиле Quake с кодировкой ISO-8859-1 (Latin-1) | — |
| `fmt=w` | Буква-код формата | Растровый шрифт в стиле Quake с кодировкой Windows-1252 (больше символов, чем в Latin-1) | — |
| `fmt=k` | Буква-код формата | Растровый шрифт в стиле Quake с кодировкой KOI8-U (распространена в русскоязычном сообществе Quake) | — |
| `fmt=h` | Буква-код формата | Растровый шрифт в стиле Half-Life — все символы расположены в один ряд на изображении | — |
| `aspect=0.5` | Дробное число | Сжимает растровый шрифт по горизонтали на заданный коэффициент | `1` (без сжатия) |
| [`style`](../39-entity-keys-reference/01-worldspawn-common-keys.md#style) | Список модификаторов через запятую | Уточнение подбора системного шрифта по имени семейства (жирность, курсив и т.д.), используется только при обращении к системным шрифтам через `fontconfig` | — |

## Примеры

- Мод задаёт `con_textfont "trebuchet"` и `vid_conautoscale "1.5"`, получая чёткий, крупный, современно выглядящий шрифт во всём текстовом интерфейсе игры вместо пиксельного шрифта по умолчанию — при этом файл `trebuchet.ttf` может как лежать в системной папке шрифтов Windows, так и быть добавлен прямо в архив мода.
- Разработчик подключает моноширинный шрифт с зелёным оттенком специально для отладочной консоли, не трогая при этом основной шрифт остального интерфейса: `gl_font "cour?col=0,1,0"`.
- Мод поставляет собственный шрифт `fonts/mymod.ttf` внутри своего pk3-архива и указывает `con_textfont "fonts/mymod"` — движок находит и подключает его напрямую из архива, без необходимости устанавливать шрифт в систему игрока.
