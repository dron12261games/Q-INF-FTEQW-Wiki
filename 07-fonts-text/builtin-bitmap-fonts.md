## Что это даёт геймдизайнеру

Весь текст в игре (консоль, меню, HUD, диалоги) должен где-то брать изображения символов. Движок изначально рисует текст классическим способом Quake — простой растровой таблицей символов фиксированного размера («шрифт-картинка»), и при этом позволяет модам полностью заменить эту таблицу собственной, нарисованной художником, чтобы получить уникальный визуальный стиль текста без необходимости работать с настоящими шрифтовыми файлами.

---

## Интерфейс настройки

Базовый набор символов движок читает из ресурса с именем `conchars` (изображение таблицы всех печатаемых знаков в едином стиле шрифта Quake) — этот ресурс можно переопределить, просто положив собственное изображение с тем же именем в файлы мода (см. [«Классические одиночные пакеты (.pak)»](../01-archives-packaging/pak-archives.md) про то, как ресурсы мода перекрывают ресурсы игры по умолчанию). Кроме основного шрифта консоли, отдельным ресурсом можно заменить фоновую картинку консоли (задаётся переменной [`gl_conback`](../38-cvars-reference/01-video-rendering-cvars.md#gl_conback), стандартное значение указывает на графику `gfx/conback.lmp`, а для Hexen II и Quake II используются свои традиционные пути `gfx/menu/conback.lmp` и `pics/conback.pcx`).

Специальные символы Quake (жёлтые цифры, полосы прогресса, значки) доступны из любого печатаемого текста через управляющую escape-последовательность в тексте — символы диапазона `^Ue000`–`^Ue0ff` соответствуют классическому набору символов Quake, а диапазон `^Ue100`–`^Ue1ff` используется для вывода некоторых иконок HUD. Произвольный символ Юникода можно вывести в консоль последовательностью `^UXXXX`, где `XXXX` — шестнадцатеричный код символа.

## Инженерный справочник

#### Cvar

| Cvar | Сигнатура | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| [`gl_conback`](../38-cvars-reference/01-video-rendering-cvars.md#gl_conback) | `gl_conback(string, "")` | Переопределяет фоновую картинку консоли на произвольный материал/изображение | пусто (используется `gfx/conback.lmp`) |

#### Другое

| Элемент | Синтаксис/тип | Описание |
| :--- | :--- | :--- |
| `conchars` | Имя графического ресурса | Изображение таблицы всех печатаемых знаков консольного шрифта; переопределяется одноимённым файлом мода (по умолчанию: встроенный растровый шрифт Quake) |
| `^Ue000`–`^Ue0ff` | Управляющая escape-последовательность в тексте | Диапазон кодов, соответствующий классическому набору специальных символов Quake (жёлтые цифры, рамки, полосы прогресса) |
| `^Ue100`–`^Ue1ff` | Управляющая escape-последовательность в тексте | Диапазон кодов для вывода некоторых иконок HUD прямо внутри текстовой строки |
| `^UXXXX` | Управляющая escape-последовательность в тексте | Вывод произвольного символа Юникода по его шестнадцатеричному коду |

## Примеры

- Мод-конверсия рисует собственную стилизованную таблицу символов в духе своей вселенной и кладёт её как замену `conchars`, из-за чего весь текст в игре — от консоли до меню — визуально меняется без единой строчки игрового кода.
- Автор карты выводит в HUD через QuakeC строку с последовательностью `^Ue010`, отображая специальный значок из классического набора символов Quake прямо посреди обычного текста.
- Мод устанавливает [`gl_conback "gfx/mymod/conback.tga"`](../38-cvars-reference/01-video-rendering-cvars.md#gl_conback), заменяя стандартный фон консоли на собственную атмосферную картинку без изменения самого шрифта.
