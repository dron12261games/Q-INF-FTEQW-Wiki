# Запуск игры прямо в веб-браузере

## Что это даёт геймдизайнеру

Движок можно собрать в виде веб-версии, которая целиком работает прямо во вкладке обычного браузера, без установки — как в игру на любом сайте: игрок просто заходит по ссылке и через несколько секунд загрузки оказывается в игре. Это отличный способ дать людям попробовать мод или демо-версию, не заставляя их ничего скачивать и устанавливать заранее.

## Интерфейс настройки

Чтобы разместить у себя играбельную веб-версию, понадобится набор файлов веб-сборки движка, которые обычно кладутся на обычный веб-хостинг рядом друг с другом:

- **`ftewebgl.html`** — веб-страница-обёртка, которую можно доработать под дизайн своего сайта;
- **`ftewebgl.js`** — сам движок, целиком собранный в один JavaScript-файл (рекомендуется заранее сжать его gzip'ом, чтобы страница быстрее грузилась);
- **`ftewebgl.js.mem`** — файл с данными движка, версия которого обязательно должна совпадать с версией `.js`-файла;
- **`ftewebgl.html.fmf`** — файл-манифест, поясняющий веб-версии, откуда брать игровые файлы конкретного мода (для каждого мода нужен свой манифест; несколько серверов одного мода могут пользоваться общим манифестом, чтобы браузер не скачивал одни и те же паки повторно);
- сами игровые архивы (`.pak`/`.pk3`), которые подтягиваются согласно манифесту — важная особенность: в веб-версии отдельные файлы внутри `.pk3` не должны быть сжаты стандартным способом (движок в браузере не умеет их распаковывать), поэтому для экономии трафика такие архивы вместо этого сжимают целиком снаружи, обычным gzip.

Подключиться к серверу из уже загруженной веб-версии можно двумя способами (в зависимости от того, что настроено на сервере):

- через обычную серверную переменную **[`sv_port_tcp <port>`](../38-cvars-reference/04-network-server-cvars.md#sv_port_tcp)**, которая обслуживает не только WebSocket, но и вообще весь TCP-путь сервера (включая HTTP и, при настройке TLS, `wss://`). Тогда в браузере подключаются адресом вида `ws://address:port/` или `wss://address:port/`;
- через более быстрый способ на основе технологии WebRTC, когда сервер регистрируется на «брокере» под переменной **[`sv_port_rtc /name`](../38-cvars-reference/04-network-server-cvars.md#sv_port_rtc)**, а игрок подключается командой [`connect /name`](../44-cli-commands-reference/02-client-ui-commands.md#connect) — это может дать меньшую задержку и даже позволяет браузерной версии самой хостить игру, но требует совместимого ICE/WebRTC-пути и не является универсальной заменой любому старому серверу.

Если на сервере включён [`sv_port_tcp`](../38-cvars-reference/04-network-server-cvars.md#sv_port_tcp), то встроенный веб-сервер движка сам умеет отдавать простую страницу-указатель на веб-версию игры — то есть достаточно просто открыть адрес сервера в браузере (`http://address:port/`), чтобы сразу получить ссылку на запуск (см. также [«Автоматическая веб-страница сервера и запуск игры прямо по ссылке»](../31-embedded-web-browser/in-game-web-pages.md)). Для `wss://` серверу нужен включённый [`net_enable_tls`](../38-cvars-reference/04-network-server-cvars.md#net_enable_tls) и сертификат, который примет браузер; если же сама страница игры открыта по `https://`, браузер обычно заблокирует небезопасный `ws://`. Дополнительные параметры запуска (например, автоматическое подключение к конкретному серверу) можно передать прямо в ссылке на страницу игры, например: `ftewebgl.html?+connect%20ws://example.com:27500`, хотя при встраивании страницы с другого сайта часть аргументов может быть намеренно проигнорирована. Заодно команда **[`cfg_save`](../44-cli-commands-reference/05-filesystem-system-commands.md#cfg_save)** позволяет веб-версии сохранить пользовательские настройки в local storage браузера, чтобы они не терялись между визитами на сайт (с оговоркой, что сам браузер иногда может очистить эти данные).

## Примеры

- Автор небольшого мода выкладывает у себя на сайте веб-сборку игры со своим манифестом, указывающим на собственный набор паков — теперь игроки могут попробовать мод прямо по ссылке из соцсетей.
- Организатор постоянного сервера включает [`sv_port_tcp 27500`](../38-cvars-reference/04-network-server-cvars.md#sv_port_tcp), после чего просто рассылает ссылку `http://address:27500/` — переход по ней в браузере сразу предлагает сыграть в веб-версии.
