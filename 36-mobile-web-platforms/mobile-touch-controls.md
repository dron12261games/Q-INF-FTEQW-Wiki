## Что это даёт геймдизайнеру

На устройствах с сенсорным экраном движок умеет автоматически показывать поверх игры виртуальные кнопки и джойстики — движение вперёд/назад/влево/вправо, стрельбу, прыжок, колесо оружия и кнопку меню — прямо там, где удобно тапать пальцами. Если игрок трогает экран, а такая раскладка ещё не была загружена, движок сам подключает набор элементов управления по умолчанию, так что игра остаётся играбельной даже без специальной подготовки со стороны автора мода. Практически это особенно важно для Android-порта и для браузерной сборки на сенсорных экранах; для iOS в стандартной конфигурации FTEQW нет такого же отдельного, явно поддерживаемого порта «из коробки», поэтому одинаковую готовность всех мобильных ОС обещать не стоит.

## Интерфейс настройки

Раскладка сенсорных кнопок описывается в специальном текстовом конфигурационном файле с именем **`touch.cfg`**. Если такой файл присутствует среди файлов игры/мода, движок автоматически выполняет его при первом касании экрана; если файла нет — движок подставляет встроенную раскладку по умолчанию. Такая раскладка создаётся обычными консольными командами и остаётся активной, пока вы не замените её новой или не очистите целиком.

Каждая кнопка добавляется одной строкой консольной команды **[`showpic <imagename> <placename> <x> <y> <zone> [width] [height] [touchcommand] [fadedelay]`](../44-cli-commands-reference/02-client-ui-commands.md#showpic)**:

| Параметр | Тип / формат | Описание |
| :--- | :--- | :--- |
| `imagename` | строка, путь к картинке | Путь к файлу-иконке кнопки (относительно папки игры), который будет показан на экране. |
| `placename` | строка, произвольное имя | Уникальное имя этого элемента интерфейса. Если повторно вызвать [`showpic`](../37-quakec-builtins-reference/08-csqc-rendering-builtins.md#showpic) с тем же именем, элемент будет обновлён на месте. Полностью очистить раскладку можно командой [`showpic_removeall`](../44-cli-commands-reference/02-client-ui-commands.md#showpic_removeall). |
| `x`, `y` | числа, экранные координаты | Смещение картинки относительно точки привязки [`zone`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#zone). |
| [`zone`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#zone) | строка, одно из: `TL`, `TR`, `BL`, `BR`, `MM`, `TM`, `BM`, `ML`, `MR` | Точка привязки на экране (верх/низ/середина × лево/право/центр — например `BL` = низ-лево, `MM` = центр экрана). Позволяет не зависеть от конкретного разрешения экрана устройства. |
| [`width`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#width), [`height`](../39-entity-keys-reference/01-worldspawn-common-keys.md#height) | числа, необязательные | Размер кнопки на экране в пикселях; если не заданы — используется исходный размер картинки. |
| `touchcommand` | строка, необязательная, консольная команда | Команда, выполняемая при касании/клике по кнопке — как правило, команда с `+`, начинающая непрерывное действие ([`+forward`](../44-cli-commands-reference/02-client-ui-commands.md#forward), [`+attack`](../44-cli-commands-reference/02-client-ui-commands.md#attack)), которая автоматически отпускается ([`-forward`](../44-cli-commands-reference/02-client-ui-commands.md#forward)) при отпускании пальца. |
| `fadedelay` | число, необязательное | Через сколько секунд элемент начнёт исчезать/тускнеть, если раскладка использует такой эффект. |

Дополнительно доступны переменные, тонко настраивающие поведение самого сенсорного ввода (а не расположение кнопок):

- **[`m_touchmajoraxis`](../38-cvars-reference/06-ui-console-input-cvars.md#m_touchmajoraxis)** — при боковом перемещении (страйфе) учитывать только основную ось движения пальца;
- **[`m_slidethreshold`](../38-cvars-reference/06-ui-console-input-cvars.md#m_slidethreshold)** — как далеко нужно провести пальцем, чтобы это посчиталось скольжением, а не отдельным тапом;
- **[`m_longpressthreshold`](../38-cvars-reference/06-ui-console-input-cvars.md#m_longpressthreshold)** — как долго нужно удерживать палец, чтобы это считалось долгим нажатием.

## Примеры

- Автор мода для мобильных устройств создаёт собственный `touch.cfg` с более крупными кнопками стрельбы и прыжка и добавляет новую кнопку для специального умения персонажа, привязанную к своей игровой команде.
- Игрок на планшете с маленьким экраном увеличивает [`m_slidethreshold`](../38-cvars-reference/06-ui-console-input-cvars.md#m_slidethreshold), чтобы случайные лёгкие касания при удержании телефона не вызывали нежелательного поворота камеры.
