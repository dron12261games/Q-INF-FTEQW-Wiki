# Сенсорное управление на мобильных устройствах

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Платформы: мобильные устройства и веб-браузер](./README.md)

## Что это даёт геймдизайнеру

На устройствах с сенсорным экраном (телефоны, планшеты) движок умеет автоматически показывать поверх игры виртуальные кнопки и джойстики — движение вперёд/назад/влево/вправо, стрельбу, прыжок, колесо оружия и кнопку меню — прямо там, где удобно тапать пальцами. Если игрок трогает экран, а такая раскладка ещё не была загружена, движок сам подключает набор элементов управления по умолчанию, так что игра остаётся играбельной на сенсорном устройстве даже без специальной подготовки со стороны автора мода. При этом автор мода может полностью заменить набор экранных кнопок под особенности именно своей игры.

## Интерфейс настройки

Раскладка сенсорных кнопок описывается в специальном текстовом конфигурационном файле с именем **`touch.cfg`**. Если такой файл присутствует среди файлов игры/мода, движок автоматически выполняет его при первом касании экрана; если файла нет — используется встроенная раскладка по умолчанию.

Каждая кнопка добавляется одной строкой консольной команды **`showpic <imagename> <placename> <x> <y> <zone> [width] [height] [touchcommand]`**:

| Параметр | Тип / формат | Описание |
| :--- | :--- | :--- |
| `imagename` | строка, путь к картинке | Путь к файлу-иконке кнопки (относительно папки игры), который будет показан на экране. |
| `placename` | строка, произвольное имя | Уникальное имя этого элемента интерфейса — по нему кнопку можно впоследствии скрыть/подвинуть/удалить отдельными командами `hidepic`/`movepic`/`changepic`. |
| `x`, `y` | числа, экранные координаты | Смещение картинки относительно точки привязки `zone`. |
| `zone` | строка, одно из: `TL`, `TR`, `BL`, `BR`, `MM`, `TM`, `BM`, `ML`, `MR` | Точка привязки на экране (верх/низ/середина × лево/право/центр — например `BL` = низ-лево, `MM` = центр экрана). Позволяет не зависеть от конкретного разрешения экрана устройства. |
| `width`, `height` | числа, необязательные | Размер кнопки на экране в пикселях; если не заданы — используется исходный размер картинки. |
| `touchcommand` | строка, необязательная, консольная команда | Команда, выполняемая при касании/клике по кнопке — как правило, команда с `+`, начинающая непрерывное действие (`+forward`, `+attack`), которая автоматически отпускается (`-forward`) при отпускании пальца. |

Дополнительно доступны переменные, тонко настраивающие поведение самого сенсорного ввода (а не расположение кнопок):

- **`m_touchmajoraxis`** — при боковом перемещении (страйфе) учитывать только основную ось движения пальца;
- **`m_slidethreshold`** — как далеко нужно провести пальцем, чтобы это посчиталось скольжением, а не отдельным тапом;
- **`m_longpressthreshold`** — как долго нужно удерживать палец, чтобы это считалось долгим нажатием.

## Примеры

- Автор мода для мобильных устройств создаёт собственный `touch.cfg` с более крупными кнопками стрельбы и прыжка и добавляет новую кнопку для специального умения персонажа, привязанную к своей игровой команде.
- Игрок на планшете с маленьким экраном увеличивает `m_slidethreshold`, чтобы случайные лёгкие касания при удержании телефона не вызывали нежелательного поворота камеры.
