# Кубические карты и изображения неба

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Текстуры и изображения](./README.md)

## Что это даёт геймдизайнеру

Небо в игре (или отражение окружения на блестящей поверхности) — это не плоская картинка, а панорама, окружающая игрока со всех сторон. Движок собирает такую панораму из набора из шести отдельных изображений (по одному на каждую грань воображаемого куба, окружающего сцену) — это называется **скайбоксом**, когда речь идёт о фоне неба, и **кубической картой окружения**, когда та же техника используется для отражений на поверхностях объектов.

## Интерфейс настройки

Скайбокс задаётся как набор из шести отдельных изображений с общим базовым именем и стандартными суффиксами стороны света, в любом из поддерживаемых форматов изображений (см. [«Базовые растровые форматы текстур»](./basic-raster-formats.md); движок сам подберёт нужное расширение — TGA или PNG). Само небо подключается либо через соответствующее свойство карты (специальный параметр объекта «информация об уровне» `sky` в сущности `worldspawn`, указывающий базовое имя набора изображений), либо через директиву материала (см. [«Язык описания материалов»](../08-materials-shaders/shader-script-language.md)), что позволяет назначить скайбокс не только на весь уровень, но и на отдельную декоративную поверхность.

Движок распознаёт сразу три разных общепринятых схемы именования суффиксов сторон куба, что упрощает переиспользование готовых панорам, скачанных из открытых источников без переименования файлов:

| Схема именования | Суффиксы (право/лево/зад/перёд/верх/низ) |
| :--- | :--- |
| Классическая схема Quake | `rt` / `lf` / `bk` / `ft` / `up` / `dn` |
| Короткая схема с осями | `px` / `nx` / `py` / `ny` / `pz` / `nz` |
| Развёрнутая схема с осями | `posx` / `negx` / `posy` / `negy` / `posz` / `negz` |

Кубические карты окружения для отражений подключаются похожим образом — как набор из шести изображений с теми же суффиксами — и используются в материалах поверхностей, которым нужно реалистичное отражение окружающего пространства (металл, стекло, вода); для карт формата BSPX существует дополнительная возможность автоматической привязки ближайшей кубической карты к каждой конкретной поверхности без ручной настройки на каждой из них (см. [«Расширенные лимиты карт»](../03-maps-levels-terrain/extended-bsp-limits-bsp2.md)).

## Примеры

- Уровень использует готовый набор из шести панорамных изображений закатного неба (`sky1rt.tga`, `sky1lf.tga`, `sky1bk.tga`, `sky1ft.tga`, `sky1up.tga`, `sky1dn.tga`) как фон, видимый в любом направлении; в `worldspawn` карты для этого указан ключ `"sky" "sky1"`.
- Хромированная поверхность объекта отражает заранее подготовленную кубическую карту окружения, создавая иллюзию отражения окружающей обстановки без реального просчёта отражений в реальном времени.
- Готовая HDRI-панорама, скачанная с открытого ресурса и уже нарезанная на шесть граней с именами `posx`/`negx`/`posy`/`negy`/`posz`/`negz`, подключается без переименования файлов благодаря поддержке этой альтернативной схемы суффиксов.
