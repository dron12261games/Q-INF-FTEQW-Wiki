# Автоматическая генерация карт нормалей/бликов

## Что это даёт геймдизайнеру

Полноценные PBR-материалы (см. [«PBR-материалы»](../08-materials-shaders/pbr-materials.md)) обычно требуют отдельных дополнительных текстур — карты нормалей (рельефа) и карты бликов. Но далеко не у всякого старого или простого контента такие карты подготовлены заранее художником. Движок умеет **автоматически рассчитывать приближённую карту нормалей и бликов прямо из обычной цветной текстуры**, анализируя перепады яркости на изображении как подсказку о рельефе поверхности. Это позволяет получить хоть какой-то эффект объёмного рельефа и бликов даже для контента, у которого никогда не было отдельных карт нормалей, — без привлечения художника для их ручной отрисовки.

---

## Интерфейс настройки

Эта возможность применяется автоматически самим движком, если материал или поверхность запрашивает карту нормалей/бликов (например, для современного рендеринга с реальным временем освещения — см. [«Реальное время: динамическое освещение и тени»](../09-lighting-shadows/realtime-world-lighting-shadows.md)), а соответствующий файл художником заранее не подготовлен. Специальной настройки со стороны геймдизайнера обычно не требуется — это резервный, автоматический механизм. Приоритет поиска устроен так: сначала движок пытается найти готовую полноценную карту нормалей с суффиксом **`_norm`** (например, `wall01_norm.tga` для базовой текстуры `wall01`), затем — карту высот в виде черно-белой (не цветной) текстуры с суффиксом **`_bump`**, из которой уже сам движок рассчитывает карту нормалей на лету, и только если ни того ни другого не нашлось — генерирует приближённую карту нормалей прямо из обычной цветной базовой текстуры, анализируя перепады яркости пикселей как подсказку о рельефе поверхности.

## Инженерный справочник

#### Cvar

| Cvar | Сигнатура | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| [`r_shadow_bumpscale_basetexture`](../38-cvars-reference/02-lighting-materials-cvars.md#r_shadow_bumpscale_basetexture) | `r_shadow_bumpscale_basetexture(float, "0")` | Степень выраженности рельефа при автоматической генерации карты нормалей из обычной цветной базовой текстуры (а не из `_bump`) | `0` (генерация по умолчанию отключена/минимальна) |
| [`r_shadow_bumpscale_bumpmap`](../38-cvars-reference/02-lighting-materials-cvars.md#r_shadow_bumpscale_bumpmap) | `r_shadow_bumpscale_bumpmap(float, "4")` | Степень выраженности рельефа при расчёте карты нормалей из явной карты высот `_bump` | `4` |
| [`r_shadow_heightscale_bumpmap`](../38-cvars-reference/02-lighting-materials-cvars.md#r_shadow_heightscale_bumpmap) | `r_shadow_heightscale_bumpmap(float, "1")` | Дополнительный масштаб высоты для 8-битных карт `_bump` | `1` |

#### Другое

| Элемент | Синтаксис/тип | Описание |
| :--- | :--- | :--- |
| Суффикс `_norm` | Соглашение об именовании файла | Полноценная, вручную подготовленная художником карта нормалей для базовой текстуры с этим именем; при наличии всегда имеет приоритет над автоматической генерацией |
| Суффикс `_bump` | Соглашение об именовании файла | Одноканальная карта высот (не цвет, а рельеф), из которой движок сам считает карту нормалей на лету |
| Суффикс `_gloss` | Соглашение об именовании файла | Карта бликов/глянца, определяющая силу и резкость зеркальных отражений на поверхности |
| Флаг `IF_TRYBUMP` (внутренний, определяет поведение автозагрузки) | Флаг загрузки текстуры | Если явная карта `_norm` не найдена, движок автоматически пытается загрузить и обработать вместо неё `_bump` |

## Примеры

- Старая, созданная десятилетия назад текстура кирпичной стены без всяких дополнительных карт неожиданно получает лёгкий эффект объёмного рельефа под динамическим освещением благодаря автоматически рассчитанной карте нормалей.
- Новая текстура, для которой художник уже подготовил собственную карту нормалей и бликов вручную (`wall01_norm.tga`, `wall01_gloss.tga`), использует именно эти файлы — автоматический расчёт для неё не применяется.
- Художник, не желающий вручную рисовать полноценную RGB-карту нормалей, готовит простую одноканальную карту высот `wall01_bump.tga` — движок сам превращает её в нормали, а параметр [`r_shadow_bumpscale_bumpmap`](../38-cvars-reference/02-lighting-materials-cvars.md#r_shadow_bumpscale_bumpmap) регулирует итоговую выраженность рельефа.
