# Стереоскопические режимы вывода

## Что это даёт геймдизайнеру

Даже без VR-гарнитуры движок умеет выводить картинку в стереоскопическом 3D-режиме — раздельным изображением для левого и правого глаза, создающим ощущение объёма при просмотре через специальные очки (в том числе простейшие цветные анаглифные очки) или на совместимом с 3D мониторе/телевизоре. Это может быть полезно для демонстрационных стендов, специализированных инсталляций или просто как необычный визуальный режим для энтузиастов старой технологии «3D-кино».

## Интерфейс настройки

Управляется тремя переменными движка:

| Переменная | Тип / формат | Описание | Значение по умолчанию |
|---|---|---|---|
| [`r_stereo_method`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_method) | Целое число `0`-`5` | Выбирает конкретный способ вывода стереоизображения (см. таблицу значений ниже). Требует перезапуска видеоподсистемы ([`vid_restart`](../44-cli-commands-reference/02-client-ui-commands.md#vid_restart)) для значения `1` | `0` |
| [`r_stereo_separation`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_separation) | Число (в игровых единицах) | Расстояние между «глазами» виртуальной камеры — по сути имитирует расстояние между настоящими глазами человека; ненулевое значение обязательно для включения стереорендера, большее значение усиливает ощущение объёма, но может вызывать усталость глаз при слишком сильном значении | `4` |
| [`r_stereo_convergence`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_convergence) | Число (градусы) | Небольшой поворот каждого «глаза» камеры внутрь, позволяющий точнее настроить точку схождения стерео-эффекта под конкретные условия просмотра | `0` |

Значения [`r_stereo_method`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_method):

| Значение | Название режима | Описание |
| :--- | :--- | :--- |
| `0` | Выключено | Стереоскопический рендер полностью отключён, обычное плоское изображение |
| `1` | Аппаратное стерео | Использует настоящее аппаратное стерео видеокарты/монитора (OpenGL quad-buffer); требует поддержки со стороны драйвера/железа и перезапуска видеоподсистемы командой [`vid_restart`](../44-cli-commands-reference/02-client-ui-commands.md#vid_restart) |
| `2` | Красно-голубой (red/cyan) анаглиф | Раскрашивает изображения левого и правого глаза в красный и голубой (циан) каналы для просмотра в простейших цветных очках |
| `3` | Красно-синий (red/blue) анаглиф | То же самое, но с использованием синего канала вместо голубого |
| `4` | Красно-зелёный (red/green) анаглиф | То же самое, но с использованием зелёного канала вместо голубого |
| `5` | «Eye strain» (перекрёстный / кроссглазый режим) | Экспериментальный режим для просмотра без очков методом скрещивания взгляда (cross-eyed viewing) — изображения левого и правого глаза выводятся рядом, поменяны местами |

---

## Примеры

- Пользователь без VR-гарнитуры, но с классическими красно-голубыми анаглифными очками включает [`r_stereo_method "2"`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_method), чтобы почувствовать объём картинки на обычном мониторе.
- На демонстрационном стенде с настоящим стереомонитором и аппаратной поддержкой активируется [`r_stereo_method "1"`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_method) и выполняется [`vid_restart`](../44-cli-commands-reference/02-client-ui-commands.md#vid_restart) для полноценного, не требующего цветных очков объёмного изображения.
- Энтузиаст без специального оборудования и очков экспериментирует с [`r_stereo_method "5"`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_method), приучая себя смотреть на экран методом скрещивания взгляда для получения объёмной картинки без каких-либо дополнительных аксессуаров.
- Для усиления ощущения глубины на большом экране увеличивается [`r_stereo_separation`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_separation) до `8`, а лёгкая коррекция точки схождения выполняется через [`r_stereo_convergence "2"`](../38-cvars-reference/01-video-rendering-cvars.md#r_stereo_convergence).
