# Анимация текстурных координат (вращение/скролл/волны)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Материалы и шейдеры](./README.md)

## Что это даёт геймдизайнеру

Эта возможность позволяет заставить текстуру двигаться по поверхности объекта — скроллить, вращаться, покачиваться волной, растягиваться и сжиматься — без создания настоящей анимации из отдельных кадров и без каких-либо изменений в самой картинке. Это стандартный и очень дешёвый по стоимости способ оживить воду, лаву, конвейерные ленты, портальные поверхности и подобные эффекты.

## Интерфейс настройки

Указывается директивой **`tcMod`** внутри слоя материала (см. [«Язык описания материалов»](./shader-script-language.md)) — можно указать сразу несколько модификаторов, они применяются по очереди друг за другом в порядке перечисления:

```
{
    map textures/water.tga
    tcMod scroll 0.1 0.05    // плавное движение текстуры по осям
    tcMod turb 0 0.2 0 1.5   // волнообразное покачивание
    tcMod rotate 30          // равномерное вращение (градусов в секунду)
}
```

### Полный список модификаторов `tcMod`

| Модификатор | Синтаксис | Описание влияния на движок | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `scroll` | `<скорость по U> <скорость по V>` | Плавное непрерывное движение (прокрутка) текстуры по горизонтальной и вертикальной координатам, скорость измеряется в текстурных единицах в секунду | без движения |
| `rotate` | `<градусов в секунду>` | Равномерное вращение текстуры вокруг центра (0.5, 0.5) | без вращения |
| `scale` | `<множитель по U> <множитель по V>` | Растягивает/сжимает текстурные координаты, изменяя видимый масштаб (плотность повторения) текстуры на поверхности | `1 1` |
| `stretch` | `<волновая функция> <база> <амплитуда> <фаза> <частота>` | Периодически растягивает и сжимает текстуру целиком по волновой функции — даёт эффект стробоскопической пульсации размера текстуры | — |
| `transform` | `<m00> <m01> <m10> <m11> <t0> <t1>` | Произвольное линейное преобразование координат (матрица 2×2 плюс смещение) для случаев, когда простых `scroll`/`rotate`/`scale` недостаточно | единичная матрица |
| `turb` | `<база> <амплитуда> <фаза> <частота>` | Волнообразное покачивание текстуры («турбулентность»), классический эффект дрожащей воды/лавы из оригинального Quake | — |
| `page` | `<кол-во кадров> <кол-во столбцов> <кол-во строк>` | Переключение между кадрами текстуры, размещёнными сеткой в одной текстурной «странице» (атласе), с течением времени — способ покадровой анимации без множества отдельных файлов | — |

### Генерация координат: `tcGen` (он же `texgen`)

Директива **`tcGen`** заменяет обычные текстурные координаты модели полностью автоматически рассчитываемыми:

| Значение | Описание влияния на движок |
| :--- | :--- |
| `base` | Обычные текстурные координаты, как заданы в самой геометрии (используется по умолчанию) |
| `lightmap` | Координаты запечённой карты освещения (лайтмапа) вместо обычной развёртки текстуры |
| `environment` | Координаты рассчитываются на основе направления взгляда камеры относительно нормали поверхности — классический эффект скользящего отражения окружения (хром, полированный металл) |
| `vector` | Координаты рассчитываются проекцией вершины на два явно заданных вектора (используется для проекционных эффектов) |
| `normal` | Координаты берутся напрямую из нормали поверхности в данной точке |
| `svector` / `tvector` | Координаты берутся из касательного вектора (tangent/binormal) поверхности — используется для эффектов, зависящих от направления UV-развёртки |
| `reflect` | Полное зеркальное отражение направления взгляда относительно нормали — более точный аналог `environment` для настоящих отражающих поверхностей |
| `skybox` / `wobblesky` | Специальные режимы генерации координат для рисования кубической текстуры неба (обычной или слегка «покачивающейся») |

## Примеры

- Поверхность лавы использует комбинацию `tcMod turb` (волнообразное покачивание) и `tcMod scroll` (медленный скролл) для эффекта тягучего движения.
- Вращающийся телепортный портал использует `tcMod rotate` с постоянной скоростью вращения текстуры вокруг центра, создающее эффект затягивающего вихря.
- Анимированная приборная панель использует `tcMod page`, переключая кадры индикатора, размещённые сеткой на одной текстуре, без загрузки отдельных файлов кадров.
- Хромированная поверхность использует `tcGen environment` для имитации отражения окружения без реального рейтрейсинга.

## Практический пример: полный материал закрученного телепортного портала

```
textures/fx/teleport_vortex
{
	surfaceparm nolightmap
	cull disable
	sort additive
	{
		map textures/fx/vortex_rings.tga
		blendfunc add
		tcMod rotate 180
		tcMod scale 1.5 1.5
		rgbGen wave sin 0.6 0.4 0 0.8
	}
	{
		map textures/fx/vortex_streaks.tga
		blendfunc add
		tcMod rotate -90
		tcMod stretch sin 1 0.3 0 1.2
	}
}
```

Построчный разбор: `surfaceparm nolightmap` отключает запечённое освещение для этой поверхности — эффект вихря должен светиться сам по себе, независимо от освещения уровня. `cull disable` рисует поверхность с обеих сторон, чтобы вихрь был виден, с какой стороны портала на него ни смотри. `sort additive` гарантирует, что материал рисуется в фазе аддитивных эффектов, после всей обычной геометрии сцены. Первый слой рисует кольца вихря, быстро вращающиеся по часовой стрелке на 180 градусов в секунду (`tcMod rotate 180`), при этом дополнительно растянутые в полтора раза (`tcMod scale 1.5 1.5` — уменьшает видимую плотность узора), а их яркость пульсирует по синусоиде между 0.2 и 1.0 с частотой 0.8 Гц (`rgbGen wave sin`), создавая мерцающее свечение. Второй слой аддитивно добавляет полосы-«лучи», вращающиеся в противоположную сторону (`tcMod rotate -90` — контрвращение усиливает ощущение затягивающего водоворота) и одновременно периодически растягивающиеся и сжимающиеся целиком по синусоиде (`tcMod stretch`) с базой 1, амплитудой 0.3 и частотой 1.2 Гц, что придаёт эффекту дополнительную пульсацию.
