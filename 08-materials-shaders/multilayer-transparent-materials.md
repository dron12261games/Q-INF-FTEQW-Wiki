## Что это даёт геймдизайнеру

Один материал (см. [«Язык описания материалов»](./shader-script-language.md)) может состоять из нескольких независимых слоёв («проходов»), накладываемых друг на друга в заданном порядке — например, базовая текстура, поверх неё полупрозрачная плёнка грязи, а поверх всего — светящийся узор. Каждый слой может иметь собственный способ смешивания с уже нарисованным изображением: обычное наложение по прозрачности, аддитивное сложение яркости (для света и огня), умножение (для теней и грязи) и другие. Это позволяет создавать визуально сложные поверхности — стекло, воду, слизь, светящиеся эффекты — без необходимости в специальных программных шейдерах, одним только описанием слоёв.

---

## Интерфейс настройки

Каждый слой материала — это отдельный блок `{ ... }` внутри общего описания материала в `.shader`-файле, содержащий как минимум ссылку на текстуру ([`map`](../40-shader-directives-reference/02-shader-stage-directives.md#map)) и способ смешивания со слоями под ним ([`blendfunc`](../40-shader-directives-reference/02-shader-stage-directives.md#blendfunc)):

```
{
    map textures/glass_base.tga
}
{
    map textures/glass_grime.tga
    blendfunc blend       // обычное наложение с учётом прозрачности
}
{
    map textures/glass_glow.tga
    blendfunc add          // складывание яркости — эффект свечения
}
```

Порядок отрисовки самого материала относительно других объектов на сцене (например, чтобы прозрачные поверхности рисовались после непрозрачных) задаётся директивой [`sort`](../40-shader-directives-reference/01-shader-toplevel-directives.md#sort) на уровне всего материала.

### Готовые именованные режимы `blendfunc`

Помимо явного указания пары GL-факторов (см. таблицу ниже), директива [`blendfunc`](../40-shader-directives-reference/02-shader-stage-directives.md#blendfunc) понимает несколько удобных именованных сокращений:

| Ключевое слово | Эквивалент | Описание влияния на движок |
| :--- | :--- | :--- |
| `blend` | `gl_src_alpha gl_one_minus_src_alpha` | Классическое наложение с учётом альфа-канала — стандартная полупрозрачность (стекло, дым) |
| `add` | `gl_one gl_one` | Аддитивное сложение яркости с уже нарисованным изображением — используется для света, огня, свечения |
| [`filter`](../44-cli-commands-reference/02-client-ui-commands.md#filter) | `gl_dst_color gl_zero` | Умножение цвета слоя на уже нарисованный цвет — затемнение/окрашивание нижних слоёв (тени, грязь, цветные фильтры) |
| `premul` | `gl_one gl_one_minus_src_alpha` | Смешивание с уже премультиплицированной на альфа-канал текстурой — устраняет тёмную кайму («feathering») на краях полупрозрачных спрайтов с фильтрацией |
| `replace` | без смешивания (полная замена) | Слой полностью заменяет нижележащее изображение, как будто прозрачности не существует |

### Явное указание пары факторов смешивания (`blendfunc <src> <dst>`)

Если ни одно из именованных сокращений не подходит, можно явно указать пару стандартных факторов смешивания OpenGL (можно как с префиксом `gl_`, так и без него):

| Фактор | Роль в формуле | Описание влияния на движок |
| :--- | :--- | :--- |
| `gl_zero` | src или dst | Множитель 0 — соответствующий цвет полностью игнорируется |
| `gl_one` | src или dst | Множитель 1 — соответствующий цвет учитывается полностью, без ослабления |
| `gl_src_color` | только dst | Множитель равен цвету, который рисует этот же слой (используется как фактор назначения) |
| `gl_one_minus_src_color` | только dst | Инверсия цвета этого же слоя (`1 - color layer`) |
| `gl_dst_color` | только src | Множитель равен цвету, уже нарисованному в кадре до этого слоя |
| `gl_one_minus_dst_color` | только src | Инверсия уже нарисованного цвета кадра |
| `gl_src_alpha` | src или dst | Множитель равен прозрачности этого слоя |
| `gl_one_minus_src_alpha` | src или dst | Инверсия прозрачности этого слоя (`1 - alpha`) |
| `gl_dst_alpha` | src или dst | Множитель равен альфа-каналу, уже находящемуся в буфере кадра |
| `gl_one_minus_dst_alpha` | src или dst | Инверсия альфа-канала буфера кадра |

Итоговый видимый цвет пикселя вычисляется по формуле `result = (color_layer × src) + (already_drawn_color × dst)`, где `src` и `dst` — выбранные из таблицы факторы.

### Значения директивы `sort` (порядок отрисовки материала)

| Значение | Числовой эквивалент | Когда рисуется материал |
| :--- | :--- | :--- |
| [`portal`](../40-shader-directives-reference/01-shader-toplevel-directives.md#portal) | 1 | Первым, ещё до неба — используется для содержимого порталов/зеркал |
| `sky` (или `distance`) | 2 | Небо — рисуется раньше обычной геометрии, создавая иллюзию бесконечной удалённости |
| `opaque` | 3 | Обычная непрозрачная геометрия уровня (используется по умолчанию для большинства материалов без [`blendfunc`](../40-shader-directives-reference/02-shader-stage-directives.md#blendfunc)) |
| `decal` (или `litdecal`) | 4 | Наклейки поверх уже нарисованной непрозрачной геометрии (следы от пуль, кровь, трещины) |
| `seethrough` | 5 | Полупрозрачные поверхности с малым влиянием на видимость сквозь них |
| `banner` | 6 | Плоские декоративные объекты (флаги, растяжки) |
| [`underwater`](../41-particle-directives-reference/02-particle-spawn-behaviour-directives.md#underwater) (или `fog`) | 7–8 | Материалы, связанные с туманом или подводными эффектами |
| `blend` | 9 | Обычная полупрозрачная геометрия — рисуется после всей непрозрачной сцены |
| `additive` | 10 | Аддитивные эффекты (огонь, свет, магия) — рисуются позже обычной прозрачности |
| `nearest` (или `hud`) | 16 | Элементы, которые всегда должны рисоваться поверх всего остального (HUD-элементы, вид от первого лица) |
| произвольное число `0`–`16` | — | Материал также принимает числовое значение сортировки напрямую (для совместимости со старыми `.shader`-файлами Quake III, числа автоматически переводятся в перечисленные выше категории) |

## Практический пример: полный материал мокрого оконного стекла с бликами и потёками грязи

```
textures/glass/dirty_window
{
	sort seethrough
	cull none
	{
		map textures/glass/glass_base.tga
		blendfunc gl_src_alpha gl_one_minus_src_alpha
		rgbGen identity
	}
	{
		map textures/glass/glass_grime.tga
		blendfunc filter
		tcMod scroll 0.01 0.005
	}
	{
		map textures/glass/glass_glow.tga
		blendfunc add
		rgbGen wave sin 0.2 0.15 0 0.5
	}
}
```

Построчный разбор: [`sort seethrough`](../40-shader-directives-reference/01-shader-toplevel-directives.md#sort) сообщает движку, что этот материал полупрозрачен и должен рисоваться после всей непрозрачной геометрии уровня, но с минимальным влиянием на видимость через него (в отличие от полноценного `blend`). [`cull none`](../40-shader-directives-reference/01-shader-toplevel-directives.md#cull) отключает отбрасывание невидимых с обратной стороны граней — стекло должно быть видно с обеих сторон. Первый слой рисует базовое стекло с классической альфа-прозрачностью через явную пару GL-факторов (`gl_src_alpha`/`gl_one_minus_src_alpha`) и неизменённым цветом текстуры ([`rgbGen identity`](../40-shader-directives-reference/02-shader-stage-directives.md#rgbgen)). Второй слой накладывает текстуру грязных потёков через сокращение [`filter`](../44-cli-commands-reference/02-client-ui-commands.md#filter) (умножение на уже нарисованный цвет — грязь реально затемняет то, что под ней), при этом сама текстура грязи медленно «плывёт» по стеклу ([`tcMod scroll`](../40-shader-directives-reference/02-shader-stage-directives.md#tcmod) со скоростью 0.01 и 0.005 текстурных единиц в секунду по осям U и V — как будто по стеклу медленно стекает влага). Третий слой аддитивно ([`blendfunc add`](../40-shader-directives-reference/02-shader-stage-directives.md#blendfunc)) добавляет лёгкий блик, яркость которого плавно пульсирует по синусоиде между 0.05 и 0.35 с частотой 0.5 Гц (`rgbGen wave [sin](../37-quakec-builtins-reference/01-math-vector-builtins.md#sin) 0.2 0.15 0 0.5`), создавая эффект бликов от проходящего света.

---

## Примеры

- Оконное стекло — комбинация базового полупрозрачного слоя и слоя бликов, накладываемого аддитивно поверх него.
- Материал лужи грязи — базовая текстура пола, поверх которой полупрозрачным слоем накладывается текстура грязных разводов.
