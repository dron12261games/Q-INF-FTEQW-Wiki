# Формулы цвета и прозрачности (rgbGen/alphaGen)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Материалы и шейдеры](./README.md)

## Что это даёт геймдизайнеру

Помимо самой текстуры, каждый слой материала может иметь дополнительно вычисляемый цвет и прозрачность — не жёстко заданные раз и навсегда, а рассчитываемые по формуле в реальном времени: пульсация яркости, мерцание, изменение прозрачности в зависимости от освещения сцены или расстояния до камеры. Это позволяет создавать оживлённые, реагирующие на игровые условия поверхности (например, светящиеся вывески, которые действительно тускнеют и разгораются, или предметы, плавно проявляющиеся из невидимости) без единой строчки программного шейдера.

## Интерфейс настройки

Задаётся директивами **`rgbGen`** (управление цветом) и **`alphaGen`** (управление прозрачностью) внутри слоя материала:

```
{
    map textures/sign_glow.tga
    rgbGen wave sin 0.5 0.5 0 1     // плавная пульсация яркости по синусоиде
    alphaGen wave sin 0.3 0.7 0 0.5 // независимая пульсация прозрачности
}
```

### Полный список режимов `rgbGen`

| Режим | Синтаксис | Описание влияния на движок | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `identity` | без аргументов | Цвет остаётся неизменным (белый, без модификации) | используется, если `rgbGen` не указан вовсе для непрозрачных слоёв |
| `identityLighting` | без аргументов | То же, но с поправкой на общую формулу пересвета движка (overbright) | используется по умолчанию для первого слоя, если освещение сцены включено |
| `wave <функция> <база> <амплитуда> <фаза> <частота>` | функция + 4 числа | Цвет пульсирует по волновой функции (полный список волновых функций — ниже) | — |
| `entity` | без аргументов | Используется собственный цвет объекта, устанавливаемый из игровой логики (например, окрашивание моделей в цвет команды) | — |
| `oneMinusEntity` | без аргументов | Обратное значение цвета объекта (инверсия: `1 - цвет`) | — |
| `vertex` | без аргументов | Цвет берётся из вершинных данных геометрии (запечённая цветовая информация в модели или карте) | — |
| `oneMinusVertex` | без аргументов | Обратное значение вершинного цвета | — |
| `exactVertex` | без аргументов | Вершинный цвет без дополнительной коррекции яркости движком (точное значение как записано в геометрии) | — |
| `lightingDiffuse` | без аргументов | Цвет рассчитывается из настоящего динамического освещения сцены в этой точке — слой ведёт себя как обычная затенённая поверхность | автоматически применяется к моделям, если материал не задаёт свой `rgbGen` |
| `entityLighting` | без аргументов | Комбинация цвета объекта и динамического освещения | — |
| `const <r> <g> <b>` (или `constant`) | три числа 0.0–1.0 | Постоянный, жёстко заданный цвет | — |
| `srgb <r> <g> <b>` (или `srgbconst`) | три числа 0.0–1.0 в sRGB | То же самое, что `const`, но значения интерпретируются в цветовом пространстве sRGB (удобно для цвета, подобранного в графическом редакторе) | — |
| `topcolor` | без аргументов | Использует «верхний» цвет игрока/команды (классический механизм окраски скинов Quake) | — |
| `bottomcolor` | без аргументов | Использует «нижний» цвет игрока/команды | — |

### Полный список режимов `alphaGen`

| Режим | Синтаксис | Описание влияния на движок | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `identity` | без аргументов | Прозрачность полностью непрозрачна (1.0), без модификации | используется, если `alphaGen` не указан |
| `vertex` | без аргументов | Прозрачность берётся из вершинных данных геометрии | автоматически подставляется, если `rgbGen vertex` указан, а `alphaGen` — нет |
| `entity` | без аргументов | Прозрачность берётся из значения, устанавливаемого из игровой логики для конкретного объекта (например, плавное появление/исчезание объекта) | — |
| `wave <функция> <база> <амплитуда> <фаза> <частота>` | функция + 4 числа | Прозрачность пульсирует по волновой функции | — |
| `lightingSpecular` | без аргументов | Прозрачность рассчитывается на основе бликовой (зеркальной) составляющей освещения — используется для эффектов блеска | — |
| `const <значение>` (или `constant`) | одно число 0.0–1.0 | Постоянная прозрачность | — |
| `portal <дистанция>` | одно число, игровые единицы | Прозрачность зависит от дистанции портала/зеркала | `256` |

### Волновые функции (используются в `rgbGen wave`, `alphaGen wave`, `tcMod stretch`, `deformVertexes wave/move`)

Каждая волновая функция принимает четыре числовых параметра: **база** (среднее значение), **амплитуда** (размах колебания), **смещение по фазе** и **частота** (сколько колебаний в секунду).

| Функция | Форма волны | Описание |
| :--- | :--- | :--- |
| `sin` | Плавная синусоида | Гладкое, симметричное колебание значения вверх-вниз |
| `triangle` | Треугольная волна | Линейный рост и линейный спад без резких переходов |
| `square` | Прямоугольная волна | Резкое переключение между двумя значениями (база−амплитуда и база+амплитуда) без плавного перехода |
| `sawtooth` | Пилообразная волна | Плавный линейный рост значения, затем мгновенный сброс в начало |
| `inversesawtooth` | Обратная пилообразная волна | Мгновенный скачок вверх, затем плавный линейный спад |
| `noise` | Случайное мерцание | Псевдослучайное значение без чёткой периодичности — полезно для эффекта неисправной лампы или помех |

## Практический пример: полный материал светящейся вывески с миганием

```
textures/props/neon_sign_broken
{
	surfaceparm nodlight
	{
		map textures/props/neon_sign_base.tga
		rgbGen identity
	}
	{
		map textures/props/neon_sign_glow.tga
		blendfunc gl_one gl_one
		rgbGen wave noise 0.6 0.4 0 3
		alphaGen wave square 0.5 0.5 0 0.2
	}
}
```

Построчный разбор: `surfaceparm nodlight` отключает получение динамических точечных теней/освещения на этой поверхности, чтобы неоновая подсветка выглядела как самосветящийся объект, а не как обычная затенённая геометрия. Первая стадия рендера рисует базовую неосвещённую текстуру корпуса вывески (`rgbGen identity` — цвет текстуры используется как есть, без модификаций). Вторая стадия аддитивно (`blendfunc gl_one gl_one` — результат складывается с уже нарисованным изображением, а не заменяет его) накладывает светящуюся маску: её яркость хаотично «дёргается» функцией `wave noise` с базой 0.6, амплитудой 0.4, без сдвига фазы, с частотой 3 колебания в секунду — получается эффект нестабильной, потрескивающей лампы; при этом прозрачность этой же маски резко переключается по прямоугольной волне (`alphaGen wave square`) с базой 0.5, амплитудой 0.5 (то есть между 0 и 1) и частотой 0.2 Гц (раз в 5 секунд) — вывеска на секунду полностью гаснет, как будто теряет контакт, а затем резко включается обратно.

## Примеры

- Индикатор здоровья на объекте плавно пульсирует красным цветом по синусоиде (`rgbGen wave sin`), привлекая внимание игрока.
- Материал призрачного объекта использует `alphaGen entity` совместно с игровой логикой, плавно меняющей числовое значение прозрачности объекта, создавая эффект появления/растворения силуэта.
- Неисправная неоновая вывеска использует `rgbGen wave noise` для эффекта случайного мерцания, как будто лампа вот-вот перегорит.
- Скин игрока использует `rgbGen topcolor`/`bottomcolor`, чтобы автоматически подстраивать цвет формы под выбранный игроком цвет команды.
