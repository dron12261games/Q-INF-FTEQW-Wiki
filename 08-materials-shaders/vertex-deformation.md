# Деформация геометрии по формулам (deformvertexes)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Материалы и шейдеры](./README.md)

## Что это даёт геймдизайнеру

Материал (см. [«Язык описания материалов»](./shader-script-language.md)) может не только менять внешний вид поверхности, но и **физически деформировать саму геометрию объекта**, на который он нанесён, — покачивать её волнами, растягивать по нормали к поверхности, придавать эффект автоматической анимации. Это позволяет, например, заставить флаг колыхаться на ветру или траву покачиваться, вообще не имея отдельной костной анимации — всё держится исключительно на формуле, описанной в материале.

## Интерфейс настройки

Задаётся директивой **`deformVertexes`** на уровне всего материала (не отдельного слоя), можно указать несколько деформаций подряд — они применяются последовательно одна за другой:

```
{
    deformVertexes wave 100 sin 0 4 0 1   // волнообразное смещение вершин
    {
        map textures/flag.tga
    }
}
```

### Полный список видов деформации

| Вид деформации | Синтаксис | Описание влияния на движок |
| :--- | :--- | :--- |
| `wave` | `<плотность волны> <волновая функция> <база> <амплитуда> <фаза> <частота>` | Самый универсальный вид: каждая вершина смещается вдоль своей нормали по волновой функции, при этом фаза волны дополнительно зависит от положения вершины в пространстве, поделённого на указанную «плотность волны» — это создаёт не синхронное, а бегущее, перетекающее по поверхности покачивание (именно так колышется классический флаг или водная гладь) |
| `normal` | `<амплитуда> <частота>` | Смещает каждую вершину вдоль её нормали случайным образом со временем, создавая эффект лёгкого «дрожания» поверхности (например, у щупалец или органических объектов) |
| `bulge` | `<ширина> <высота> <скорость>` | Придаёт поверхности эффект «раздувания»/пульсации объёма по синусоиде на основе текстурных координат — классический эффект, использовавшийся в Quake III для пульсирующих грибов и органических объектов |
| `move` | `<X> <Y> <Z> <волновая функция> <база> <амплитуда> <фаза> <частота>` | Сдвигает всю геометрию целиком как одно целое вдоль указанного вектора по волновой функции (например, плавное покачивание всего объекта вверх-вниз) |
| `autosprite` | без аргументов | Автоматически разворачивает плоскость (обычно четырёхугольник) так, чтобы она всегда была направлена на камеру целиком как единый спрайт — используется для эффектов вроде вспышек и частиц, реализованных как обычная геометрия карты |
| `autosprite2` | без аргументов | Похожий эффект, но сохраняющий одну из осей четырёхугольника фиксированной (например, вертикаль) — подходит для эффектов вроде лазерных лучей или ветвящихся молний |
| `projectionShadow` | без аргументов | Деформирует геометрию в плоскую проекцию тени, отбрасываемой на землю (упрощённый способ рисования теней без полноценного динамического освещения) |
| `text0`…`text7` | без аргументов | Специальная деформация, зарезервированная для внутреннего рендеринга текста движком |

## Практический пример: полный материал колышущегося флага

```
textures/props/banner_cloth
{
	cull disable
	deformVertexes wave 60 sin 0 6 0 0.6
	deformVertexes bulge 100 2 1.5
	{
		map textures/props/banner_diffuse.tga
		rgbGen identity
	}
	{
		map textures/props/banner_diffuse.tga
		blendfunc filter
		rgbGen lightingDiffuse
	}
}
```

Построчный разбор: `cull disable` рисует полотнище с обеих сторон, поскольку тонкая геометрия флага без этого была бы не видна с обратной стороны. Первая деформация `deformVertexes wave 60 sin 0 6 0 0.6` смещает каждую вершину вдоль нормали по синусоиде с базой 0 (полотнище в среднем не смещено) и амплитудой 6 единиц, при этом делитель плотности волны `60` заставляет разные участки ткани колебаться со сдвигом фазы в зависимости от их положения — получается не единое дрожание, а настоящая бегущая волна вдоль полотнища, с частотой 0.6 колебания в секунду (медленное, тяжёлое колыхание плотной ткани). Вторая деформация `deformVertexes bulge 100 2 1.5` дополнительно добавляет лёгкую пульсацию объёма поверх основной волны, придавая ткани более естественный, неровный вид. Первый слой рисует базовую текстуру герба без модификации цвета (`rgbGen identity`), а второй слой дополнительно умножает (`blendfunc filter`) её на рассчитанное динамическое освещение сцены (`rgbGen lightingDiffuse`), из-за чего флаг корректно затемняется в тени и высвечивается на солнце, оставаясь при этом полностью управляемым формулами без единого кадра настоящей анимации.

## Примеры

- Флаг на флагштоке колышется по формуле `deformVertexes wave` с фазой, зависящей от положения вдоль полотнища, — без единого кадра настоящей анимации.
- Куст травы на уровне слегка покачивается на ветру за счёт `deformVertexes wave` с небольшой амплитудой и малой плотностью волны, применённой прямо в материале его текстуры.
- Эффект вспышки выстрела реализован как простой четырёхугольник с `deformVertexes autosprite`, всегда развёрнутый на камеру, независимо от угла обзора игрока.
- Молния между двумя точками использует `deformVertexes autosprite2`, сохраняя вытянутость луча вдоль своей длины при развороте на камеру только по толщине.
