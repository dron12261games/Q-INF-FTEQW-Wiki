# Быстрый старт: первые команды

> Раздел: [Введение](./README.md)

Эта страница — короткая практическая шпаргалка для самого первого знакомства с движком. Подробное описание каждой темы вынесено в соответствующие разделы основной вики.

## Открываем консоль

Консоль открывается клавишей `` ` `` (тильда, обычно под Esc) или сочетанием `Shift+Esc`. Это текстовое поле ввода, куда можно вводить команды и переменные движка.

Две полезные команды для самостоятельного изучения того, что вообще умеет движок:

- `cvarlist` — выводит список вообще всех переменных движка;
- `cmdlist` — выводит список вообще всех доступных команд.

## Базовые команды

| Команда | Что делает |
|---|---|
| `bind <клавиша> <команда>` | Привязывает команду к клавише, например `bind F12 quit` |
| `unbindall` | Снимает вообще все привязки клавиш — полезно перед тем, как настроить управление с нуля |
| `map <имя_карты>` | Запускает игру на указанной карте, например `map dm4` |
| `changelevel <имя_карты>` | Переходит на другую карту без полного пересоздания сервера (сохраняя часть состояния игры) |
| `connect <адрес>` | Подключается к серверу по IP-адресу или доменному имени |
| `reconnect` | Заново подключается к серверу, к которому вы были подключены последним |
| `disconnect` | Закрывает текущее сетевое или локальное игровое подключение |
| `cfg_save` | Сохраняет все ещё не сохранённые изменения настроек на диск |
| `echo <текст>` | Печатает произвольный текст в консоль — полезно для отладки алиасов и конфигов |
| `exec <файл.cfg>` | Построчно исполняет команды из указанного текстового конфигурационного файла |
| `alias <имя> "<команды>"` | Создаёт собственную команду-макрос, объединяющую несколько других команд |
| `toggle <cvar>` | Переключает булеву (0/1) переменную в противоположное значение — удобно вешать на одну клавишу вместо ручного набора значений |
| `wait` | Приостанавливает выполнение следующей команды в той же строке/алиасе на один кадр — нужно для последовательностей нажатий |
| `find <подстрока>` / `apropos <подстрока>` | Ищет команды и переменные, в имени или описании которых встречается указанное слово |
| `quit` | Закрывает игру |

Подробнее о привязке клавиш, алиасах и командах — в разделе [«Конфигурационные файлы и консоль»](../19-config-console/README.md).

## Переменные движка (cvar): временное и постоянное изменение

В отличие от многих других движков серии Quake, система переменных FTEQW ближе к более поздним движкам: значения можно менять как временно, так и «навсегда» (с сохранением в конфиг):

```
set sv_port 26000     ! изменить значение только на текущий сеанс работы движка
seta sv_port 26000     ! изменить значение и сразу пометить его на сохранение в конфиг-файл
```

Если ввести в консоли просто `имя_переменной значение`, не указывая `set`/`seta`, движок сам поймёт, что вы обращаетесь к переменной, и применит `set` — то есть изменение будет только временным.

## Параметры командной строки

Переменные и команды можно передать движку сразу при запуске, через командную строку, с символом `+` перед каждой:

```
fteqw +set sv_port 26000 +map dm4
```

Другие полезные параметры запуска:

| Параметр | Назначение |
|---|---|
| `-nohome` | не пытаться писать конфиги/сохранения/скриншоты в домашнюю папку пользователя |
| `-basedir <путь>` | указать корневую папку игровых данных |
| `-basegame <папка>` | указать папку основной игры |
| `-game <папка>` | указать папку мода поверх основной игры |
| `-window` | запустить рендер в оконном, а не полноэкранном режиме |
| `-manifest <файл.fmf>` | загрузить файл-манифест мода/игры |
| `-dedicated` | запустить движок в режиме выделенного сервера, без изображения |

Подробнее о структуре папок и о том, как переключаться между играми и модами — в статье [«Структура папок игры»](./directory-structure-basics.md).

## Быстрый сетевой старт

Чтобы **найти и подключиться** к чужому серверу, откройте в игре встроенное меню сетевой игры (multiplayer) — там есть браузер серверов, который сам находит доступные матчи по разным поддерживаемым протоколам (подробнее — в разделе [«Поиск серверов и мастер-серверы»](../25-server-browser-masters/README.md)).

Чтобы **поднять свой сервер**, есть два основных варианта:
1. Запустить listen-сервер (сервер и клиент одновременно на одном компьютере) и вручную настроить проброс портов в домашнем роутере.
2. Воспользоваться сторонним сервисом `frag-net.com`, который помогает игрокам находить ваш сервер, даже если вы не настраивали проброс портов, — для этого при создании сервера достаточно выставить настройку публичности сервера в режим «Holepunch».

Пример запуска выделенного сервера сразу из командной строки, с автоматическим анонсом через `frag-net.com`:

```
fteqw +set sv_public 2 +set sv_playerslots 8 +map dm4
```

## Пример типичной первой сессии в консоли

Ниже — законченная последовательность команд, которую новичок может набрать подряд сразу после первого запуска, чтобы на практике почувствовать все понятия из этой шпаргалки:

```
cvarlist name
find crosshair
seta crosshair 3
bind mouse1 +attack
bind space +jump
map dm4
cfg_save
```

Построчный разбор: первая команда выводит список всех переменных, в имени которых встречается `name` (так можно быстро найти `name` — переменную с именем игрока). Вторая ищет все команды/переменные, связанные с прицелом. Третья постоянно (с сохранением в конфиг) включает третий вариант прицела. Четвёртая и пятая привязывают стрельбу к левой кнопке мыши и прыжок к пробелу. Шестая запускает одиночную игру на карте `dm4`. Последняя команда принудительно сохраняет всё, что было изменено, чтобы не потерять настройки при следующем запуске, даже если движок закроется аварийно.
