# Установка и первый запуск

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Введение](./README.md)

## Где взять движок

Готовые сборки движка и его исходный код всегда доступны на официальном сайте проекта — **fteqw.org**. Компилятор языка QuakeC (FTEQCC) распространяется отдельно, на сайте **fteqcc.org**. Также этот репозиторий сам по себе является исходным кодом движка, который можно собрать самостоятельно (см. `documentation/Building.md` в корне репозитория).

## Установка на разных платформах

### Windows / Linux (обычный компьютер)

1. Скачайте архив с готовой сборкой движка под вашу операционную систему.
2. Распакуйте его в отдельную папку — это и будет ваш `basedir`.
3. Положите в эту же папку папку с игровыми данными нужной игры (например, `id1` для Quake) — обычно её можно скопировать из легально приобретённой копии игры (Steam, GOG и т.д.).
4. Запустите исполняемый файл движка (например, `fteqw.exe`).

> ⚠️ Важно для пользователей Windows: не переименовывайте исполняемый файл движка в `winquake.exe` или `glquake.exe` — операционная система применяет к этим именам специальную «историческую» логику совместимости, которая не нужна FTEQW и может вызвать проблемы.

### Steam

Если игра (например, ремастеры Quake I/II) установлена через Steam, движок способен самостоятельно обнаружить и использовать данные из стандартной папки `SteamApps/common/ИмяИгры`, не требуя от вас вручную копировать файлы.

### Linux/Unix — системные папки игр

Движок также умеет искать игровые данные в стандартных системных путях, принятых в Unix-подобных дистрибутивах, например:
- `/usr/share/games/quake`
- `/usr/share/games/quake2`
- `/usr/share/games/quake3`
- `/usr/share/games/hexen2`
- `/usr/share/games/halflife`
- `/usr/share/games/halflife2`

### Android

На Android игровые данные копируются в папку приложения:

```
Android/data/com.fteqw/files/id1/pak0.pak
Android/data/com.fteqw/files/id1/pak1.pak
```

### Веб-браузер

Для запуска в браузере используется отдельная веб-сборка движка — подробнее в разделе [«Платформы: мобильные устройства и веб-браузер»](../36-mobile-web-platforms/README.md).

## Half-Life и Half-Life 2

Для запуска игровой логики Half-Life 1/2 движок использует отдельный проект-прослойку **Rad Therapy**, который подгружается автоматически; для Half-Life 2 дополнительно требуется отдельный подключаемый модуль поддержки форматов Source-движка.

## Особый случай: 64-битная версия и Quake II

Если вы используете 64-битную сборку движка, для Quake II вам также потребуется 64-битная библиотека игровой логики — рекомендуется взять её из проекта **Yamagi Quake II** под вашу платформу. Это же рекомендуется сделать и для 32-битной версии на Windows — это гарантирует, что сохранения игры будут корректно работать и оставаться совместимыми между разными компьютерами.

## Первый запуск: что вы увидите

При первом запуске движок откроет окно игры (либо, если явно указан параметр `-dedicated`, запустится в режиме терминала без изображения — это режим для постоянно работающих серверов). Если игровые данные найдены корректно, вы попадёте в главное меню игры/мода. Открыть встроенную консоль движка можно клавишей `` ` `` (тильда) либо сочетанием `Shift+Esc` — это основной инструмент диагностики и настройки, который пригодится в дальнейшем. Первое, что стоит сделать в консоли сразу после первого успешного запуска, — набрать команду `version`, чтобы увидеть точный номер сборки движка и список включённых в неё подсистем (некоторые сборки компилируются без поддержки отдельных технологий, например без Vulkan или без OpenAL, и эта команда сразу покажет, чего можно не ждать от конкретной копии движка).

## Три сценария первого запуска

**Сценарий А — обычный игровой клиент.** Двойной клик по исполняемому файлу без каких-либо параметров командной строки. Движок ищет `id1` (или иную базовую игру, зашитую в конкретную сборку) рядом с собой, открывает окно с автоматически подобранным разрешением экрана и показывает главное меню. Это самый частый сценарий для игрока, который просто хочет поиграть.

**Сценарий Б — выделенный сервер без изображения.** Запуск с параметром `fteqw -dedicated +map e1m1`: движок не открывает никакого окна вообще, сразу инициализирует серверную часть, загружает указанную карту и начинает слушать входящие подключения на сетевом порту по умолчанию. Такой процесс обычно запускают на удалённой машине или в контейнере, где никто не смотрит на экран, а взаимодействие с ним идёт через терминал или удалённое администрирование (см. [«RCON и удалённое администрирование»](../27-web-server-rcon/rcon-remote-administration.md)).

**Сценарий В — тестовый запуск конкретного мода с чистыми настройками.** Запуск с параметрами `fteqw -game mymod +set fs_cnq3 0` из отдельного ярлыка позволяет разработчику мода запускать свой проект, не трогая основную установку движка и её сохранённые настройки — полезно, когда на одном компьютере параллельно тестируется несколько независимых проектов.

## Если что-то пошло не так: таблица диагностики

| Симптом | Причина | Что предпринять |
| :--- | :--- | :--- |
| Чёрный экран или графические артефакты на старом видеоадаптере (например, Intel GMA) | Драйвер видеокарты плохо поддерживает выбранный по умолчанию графический бэкенд | Принудительно включить рендер через Direct3D 9: `fteqw +set vid_renderer d3d9` |
| Сбои конкретно при использовании OpenGL-рендера | Драйвер видеокарты некорректно компилирует часть современных GLSL-шейдеров | Отключить часть современных возможностей шейдеров: `fteqw +set gl_blacklist_debug_glsl 1` |
| Настройки не сохраняются между запусками | Проблема с правами на запись в домашнюю папку или папку движка (см. [«Структура папок игры»](./directory-structure-basics.md)) | Выполнить в консоли `cfg_save` — команда сохранит текущую конфигурацию и покажет точный путь записанного файла или сообщит об ошибке доступа |
| Аварийное завершение работы сразу при запуске звука | Несовместимость системного аудиодрайвера с реализацией OpenAL | Отключить звуковую подсистему OpenAL: `fteqw +set s_al_disable 1` |
| Не находятся игровые данные при установке через Steam | Нестандартный путь установки библиотеки Steam | Указать путь вручную параметром `-basedir "путь\до\SteamApps\common\ИмяИгры"` |
| Окно открывается, но сразу сворачивается/закрывается | Конфликт полноэкранного режима с разрешением монитора | Запустить в оконном режиме: `fteqw -window` |
| Требуется быстро сбросить все пользовательские настройки к значениям по умолчанию | Повреждённый или несовместимый после обновления `config.cfg` | Запустить с параметром `-safe`, отключающим чтение большинства пользовательских конфигов при старте |
