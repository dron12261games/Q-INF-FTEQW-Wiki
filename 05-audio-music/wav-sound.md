# Стандартный звук WAV

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Звук и музыка](./README.md)

## Что это даёт геймдизайнеру

**WAV** — это базовый, самый широко поддерживаемый и наиболее совместимый формат звука в движке: звуки оружия, шаги, реплики персонажей и большинство коротких игровых эффектов традиционно хранятся именно так. Это несжатый (или почти несжатый) звук без задержки на распаковку, поэтому он отлично подходит для коротких эффектов, которые должны воспроизводиться мгновенно и часто — в отличие от сжатых форматов, которые лучше подходят для длинной фоновой музыки (см. [«Сжатая музыка и озвучка»](./compressed-music-ogg-mp3-flac-opus.md)).

## Интерфейс настройки

Звуковой файл кладётся в подпапку **`sound/`** игровой папки с расширением **`.wav`**. Ссылка на конкретный звук в игровой логике или конфигурации указывается путём внутри этой папки (например, `weapons/shotgun.wav`) — сама папка `sound/` при этом в пути не указывается, она подразумевается автоматически.

Движок при поиске звука по имени сам перебирает несколько возможных расширений (WAV, а также сжатые форматы) — если у звука с одним и тем же именем существует одновременно и `.wav`, и сжатая версия, начиная поиск с наиболее подходящего варианта. Это позволяет автору мода начать с простых WAV-заготовок, а позже подменить их сжатыми версиями без изменения самой игровой логики — имя звука в коде остаётся тем же.

## Примеры

- Классический набор звуков оружия Quake хранится и воспроизводится в формате WAV без каких-либо изменений.
- Мод добавляет новый звук получения предмета как простой `.wav`-файл в `sound/items/pickup.wav`, ссылаясь на него по этому пути из игровой логики.

## Инженерный справочник: builtin-функции и константы воспроизведения звука в QuakeC

#### Встроенные функции QuakeC

| Функция | Сигнатура | Описание |
| :--- | :--- | :--- |
| [`precache_sound`](../37-quakec-builtins-reference/05-sound-builtins.md#precache_sound) | `string(string s)` | Заранее объявляет звук движку и клиентам, загружая его с диска; должна вызываться в функции появления объекта ([`spawn`](../37-quakec-builtins-reference/03-entity-world-builtins.md#spawn)), до первого использования звука функцией [`sound`](../37-quakec-builtins-reference/05-sound-builtins.md#sound) |
| `sound` | `void(entity e, float chan, string samp, float vol, float atten, optional float speedpct, optional float flags, optional float timeofs)` | Проигрывает звук, привязанный к указанному объекту; `chan` — канал воспроизведения (см. константы `CHAN_*`); `samp` должен быть заранее закэширован через `precache_sound`; `speedpct` — скорость воспроизведения в процентах от нормальной (100 — обычная скорость, 200 — вдвое быстрее); `flags` собирается из констант `SOUNDFLAG_*`; `timeofs`, если указан отрицательным, задаёт задержку перед стартом звука |
| [`ambientsound`](../37-quakec-builtins-reference/05-sound-builtins.md#ambientsound) | `void(vector pos, string samp, float vol, float atten)` | Проигрывает звук в фиксированной точке пространства карты, начинающий звучать сразу при подключении клиента; в отличие от `sound`, такие звуки нельзя впоследствии остановить или заменить, а движок автоматически зацикливает их, если в самом звуковом файле не размечены собственные точки зацикливания |
| `stopsound` | `void(entity ent, float channel)` | Немедленно прерывает воспроизведение звука на указанном канале указанного объекта (не следует использовать с `CHAN_AUTO`) |

#### Другое

| Элемент | Синтаксис/тип | Описание |
| :--- | :--- | :--- |
| `CHAN_AUTO` | константа `float` | Автоматический канал — на нём можно одновременно проигрывать сколько угодно звуков, они не заменяют друг друга (в отличие от прочих каналов, где новый звук обрывает предыдущий на том же канале) |
| `CHAN_WEAPON` | константа `float` | Канал, традиционно используемый для звуков оружия текущего объекта |
| `CHAN_VOICE` | константа `float` | Канал, традиционно используемый для голосовых реплик объекта |
| `CHAN_ITEM` | константа `float` | Канал, традиционно используемый для звуков взаимодействия с предметами |
| `CHAN_BODY` | константа `float` | Канал, традиционно используемый для дополнительных звуков тела объекта (например, звуков движения) |
| `ATTN_NONE` | константа `float` | Звук слышен одинаково громко по всей карте, независимо от расстояния |
| `ATTN_NORM` | константа `float` | Стандартное затухание громкости звука с расстоянием |
| `ATTN_IDLE` | константа `float` | Усиленное затухание, чтобы негромкие фоновые звуки не были слышны слишком далеко |
| `ATTN_STATIC` | константа `float` | Ещё более сильное затухание, чтобы близкие статичные источники звука (например, факелы) не заглушали остальные звуки по всей карте |
| `SOUNDFLAG_NOREPLACE` | константа `float`, битовый флаг для `flags` в `sound` | Если на указанном канале объекта уже что-то проигрывается, новый вызов `sound` с этим флагом будет проигнорирован — удобно для звуков, которые безопасно пытаться запускать каждый кадр без побочных эффектов |
| `RESTYPE_SOUND` | константа `float` | Идентификатор типа ресурса «звук», используемый в обобщённых функциях работы с прекэшированными ресурсами |
