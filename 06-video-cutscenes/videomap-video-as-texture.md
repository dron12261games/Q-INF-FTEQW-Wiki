# Видео как текстура на поверхности (videomap)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Видео и катсцены](./README.md)

## Что это даёт геймдизайнеру

Вместо (или помимо) полноэкранных заставок движок умеет проигрывать видеоролик прямо как текстуру на обычной поверхности внутри игрового мира — классический пример: работающий телевизор, монитор камеры наблюдения или голографический экран, показывающий видео прямо на объекте посреди уровня, пока игрок ходит рядом и может рассматривать эту поверхность с разных сторон, как любую другую часть уровня.

## Интерфейс настройки

Настраивается ключевым словом **`videomap`** внутри описания материала поверхности (см. [«Язык описания материалов»](../08-materials-shaders/shader-script-language.md)) — вместо обычной статичной картинки в качестве текстуры указывается ссылка на видеофайл, и движок начинает проигрывать это видео прямо на поверхности в реальном времени, покадрово обновляя изображение так же, как обновлялась бы анимированная текстура. Кроме того, консольная команда для показа видео в отдельном окне интерфейса (не на поверхности в 3D-мире, а как элемент HUD/меню) использует тот же принцип отображения видеопотока на прямоугольной области экрана.

## Примеры

- Материал экрана монитора внутри уровня использует `videomap video/security_feed.roq`, из-за чего проходящий мимо игрок видит на экране проигрывающийся видеоряд, как будто это реальная работающая камера наблюдения.
- Автор мода делает интерактивный музейный экспонат — старый телевизор, показывающий зацикленный архивный видеоролик прямо на своём «экране»-поверхности.

## Практический пример: полный материал экрана с видео

```
textures/props/tv_screen
{
	{
		videomap video/news_broadcast.roq
	}
	{
		map $lightmap
		blendfunc gl_dst_color gl_zero
	}
}
```

Построчный разбор: имя материала `textures/props/tv_screen` соответствует пути, который должен быть назначен соответствующей поверхности в редакторе уровней. Первая стадия рендера (`{ ... }`) с директивой `videomap` заменяет собой обычную статичную картинку — вместо загрузки одной неподвижной текстуры движок открывает указанный видеофайл и каждый кадр обновляет содержимое текстуры новым декодированным кадром видео. Вторая стадия дополнительно накладывает запечённую карту освещения уровня (`$lightmap`) поверх видео с помощью функции смешивания `gl_dst_color gl_zero` (умножение на цвет освещения) — это нужно, чтобы экран телевизора не выглядел неестественно ярким при слабом освещении в комнате и корректно затемнялся в тени, как и остальная геометрия уровня.
