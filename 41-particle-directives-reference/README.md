# Справочник директив языка частиц (.particles)

> [⬅ Вернуться к оглавлению вики](../README.md)

Этот раздел дополняет статью [«Скриптовый язык описания частиц»](../10-particles-decals-trails/particle-script-language.md). Здесь собран построчный справочник по каждой директиве (ключевому слову) формата `.particles` — конфигурационного языка, которым описываются все эффекты частиц FTEQW: от искр и дыма до сложных многоуровневых trail-эффектов.

## Категории

- [Директивы эффекта (particle, count, die, type и другие)](./01-particle-effect-directives.md)
- [Директивы поведения и появления (spawn*, veloc*, orient* и другие)](./02-particle-spawn-behaviour-directives.md)

## Как читать эти статьи

Каждая директива описывается по единому шаблону: точный синтаксис на английском, разбор каждого параметра и единиц измерения, подробное описание визуального результата и готовые к использованию примеры блоков `.particles`.
