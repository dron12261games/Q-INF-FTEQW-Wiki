# Мгновенные сообщения через Jabber/XMPP

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Интеграция со сторонними сервисами и мессенджерами](./README.md)

## Что это даёт геймдизайнеру

Ещё один дополнительный модуль движка встраивает в игру клиент протокола обмена мгновенными сообщениями Jabber/XMPP — того же самого протокола, на котором в своё время работали многие корпоративные и общественные системы обмена сообщениями. Благодаря этому игрок может держать список друзей и переписываться с ними, не выходя из игры — полезно для сообществ, которые уже используют XMPP-сервер для общения вне игры.

## Интерфейс настройки

Модуль загружается той же командой **`plug_load`**, после чего в игре появляется команда **`xmpp`** и соответствующий пункт «Social → Social» во внутриигровом меню (виден, только если плагин загружен). Поведение клиента настраивается переменными:

- **`xmpp_nostatus`** — не показывать в чате изменения статуса собеседников (в сети/не в сети и т.п.);
- **`xmpp_showstatusupdates`** — наоборот, явно показывать обновления статуса;
- **`xmpp_autoacceptvoice`** — автоматически принимать голосовые (а также видео-) звонки от собеседников по протоколу Jingle;
- **`xmpp_autoacceptjoins`** — автоматически принимать приглашение зайти на игровой сервер, присланное собеседником прямо через XMPP (модуль умеет не только передавать текст, но и приглашать друзей напрямую на конкретный игровой сервер одним щелчком, минуя браузер серверов);
- **`xmpp_autoacceptinvites`** — автоматически принимать запрос собеседника присоединиться к вашей текущей игре (обратный случай — когда приглашают не вас, а вас просят принять чужого игрока в вашу игру);
- **`xmpp_debug`** — подробный отладочный вывод в консоль о работе клиента.

Учётные данные для входа (логин/сервер/пароль) вводятся через собственный внутриигровой интерфейс модуля, открывающийся по команде `xmpp`.

## Примеры

- Игровое сообщество, которое уже использует свой XMPP-сервер для координации кланов, подключает плагин, чтобы участники видели статус друзей прямо в игре.
- Пользователь включает `xmpp_autoacceptvoice 1`, чтобы голосовые звонки от друзей принимались сразу, без лишнего клика.
