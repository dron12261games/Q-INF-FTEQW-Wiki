# Справочник встроенных функций QuakeC (builtins)

> [⬅ Вернуться к оглавлению вики](../README.md)

Это исчерпывающий технический справочник по **встроенным функциям (builtin functions)** языка QuakeC — тем самым функциям, которые помечены в исходном коде как `= #NN;` и реализованы не на самом QuakeC, а внутри движка FTEQW на Си. Именно через них скрипты SSQC/CSQC/MenuQC получают доступ к возможностям движка: рисованию, сети, звуку, файлам, физике и так далее.

Каждая функция описана как отдельная самодостаточная статья: с точной сигнатурой, разбором каждого аргумента, подробным описанием логики работы и граничных случаев, а также готовыми к использованию примерами кода.

Материал сгруппирован по функциональным категориям, чтобы упростить навигацию по нескольким сотням функций.

## Как читать эти статьи

Каждая функция описывается по единому шаблону:

1. Оригинальное имя функции и её точная сигнатура на QuakeC (типы данных не переводятся).
2. Разбор каждого аргумента.
3. Подробное текстовое описание логики работы — без исходного кода движка, только то, что видно и ощутимо снаружи, на уровне мода.
4. Практические сценарии использования с полным, рабочим кодом на QuakeC.
