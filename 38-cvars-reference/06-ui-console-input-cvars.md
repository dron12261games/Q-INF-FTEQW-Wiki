# Интерфейс, консоль и управление

> [⬅ Вернуться к оглавлению вики](../README.md)

> [Индекс справочника cvar](./README.md)

В этой статье собраны консольные переменные FTEQW, отвечающие за консоль, экранные информационные элементы, меню и устройства ввода. Подборка опирается только на реальные определения `CVAR(...)`, `CVARF(...)`, `CVARD(...)` и `CVARFD(...)` в исходниках клиента. Описания ниже помогают быстро понять, какие настройки стоит трогать для читаемой консоли, удобного HUD и предсказуемого управления с клавиатуры, мыши, сенсора или геймпада.

## Переменные

### cl_anglespeedkey
`cvar cl_anglespeedkey(дробное, "1.5")`

#### Описание и логика работы
Множитель клавишной скорости поворота, который применяется вместе с `cl_yawspeed` и `cl_pitchspeed`, когда удерживается `+speed`. Значение `1` оставляет базовую скорость без изменений, `0` убирает дополнительное ускорение, а повышенные значения делают разворот и вертикальный взгляд заметно резче. Переменная не помечена как `CVAR_ARCHIVE`; если значение должно переживать перезапуск, задавайте его через `seta` в своём конфиге.

#### Практические сценарии использования
```cfg
seta cl_anglespeedkey "2.0" // ускорить клавишный поворот при удержании +speed
```

### cl_backspeed
`cvar cl_backspeed(дробное/пустая строка, "")`

#### Описание и логика работы
Базовая скорость движения назад. Пустое значение использует `cl_forwardspeed`, что даёт симметричное движение вперёд и назад; `0` фактически запрещает шаг назад, а большие числа всё равно будут ограничены правилами сервера и игрового мода. Переменная архивируется (`CVAR_ARCHIVE`) и обычно попадает в сохраняемую конфигурацию.

#### Практические сценарии использования
```cfg
seta cl_backspeed "300" // сделать движение назад медленнее движения вперёд
```

### cl_chatmode
`cvar cl_chatmode(целое 0-2, "2")`

#### Описание и логика работы
Определяет, как строка ввода интерпретируется при нажатии Enter. Режим `0` ближе к NetQuake и считает ввод командой, `1` ближе к Quake 3 и считает ввод чатом, а `2` использует гибридную схему QuakeWorld: известные команды выполняются, а неизвестные строки уходят в чат. Префикс `/` поддерживается всегда, а Enter с зажатым Ctrl переводит неявный чат в team chat. Переменная не помечена как `CVAR_ARCHIVE`; если значение должно переживать перезапуск, задавайте его через `seta` в своём конфиге.

#### Практические сценарии использования
```cfg
seta cl_chatmode "2" // оставить гибридный режим консоли и чата
```

### cl_clock
`cvar cl_clock(целое 0-2, "0")`

#### Описание и логика работы
Включает экранные часы реального времени. `0` отключает индикатор, `1` показывает время в 24-часовом формате, `2` — в 12-часовом формате с AM/PM; переменная полезна для стримов, турниров и длительных сессий. Переменная не помечена как `CVAR_ARCHIVE`; если значение должно переживать перезапуск, задавайте его через `seta` в своём конфиге.

#### Практические сценарии использования
```cfg
seta cl_clock "1" // показывать локальное время в 24-часовом формате
```

`cvar cl_forwardspeed(дробное, "400")`

#### Описание и логика работы

Это клиентская основа для `forwardmove`: ноль отключает поступательное движение, а слишком большие числа не обходят серверные лимиты и нужны главным образом для локальной подстройки управления. Переменная архивируется (`CVAR_ARCHIVE`) и обычно попадает в сохраняемую конфигурацию.


### cl_gameclock
`cvar cl_gameclock(целое 0-2, "0")`

#### Описание и логика работы
Показывает игровой таймер матча. `0` выключает индикатор, `1` обычно отображает прошедшее игровое время, а `2` пытается вести обратный отсчёт от `timelimit`, если сервер публикует этот параметр; в обоих случаях таймер выводится в формате `MM:SS`. Переменная не помечена как `CVAR_ARCHIVE`; если значение должно переживать перезапуск, задавайте его через `seta` в своём конфиге.

#### Практические сценарии использования
```cfg

```

### cl_iDrive
`cvar cl_iDrive(логическое, "1")`

#### Описание и логика работы
Заставляет противоположную клавишу движения автоматически подавляться, когда вы нажимаете её антипод — например, `+forward` против `+back`. Это уменьшает мёртвое время при смене направления и помогает более отзывчивому strafing-управлению, особенно на клавиатуре. Переменная не помечена как `CVAR_ARCHIVE`; если значение должно переживать перезапуск, задавайте его через `seta` в своём конфиге. Дополнительно она помечена как `CVAR_SEMICHEAT`, поэтому в некоторых режимах или правилах сервера может считаться спорной настройкой.

#### Практические сценарии использования
```cfg
seta cl_iDrive "1" // убрать задержку при смене направления на клавиатуре
```


### cl_keypad
`cvar cl_keypad(логическое, "1")`

Для Windows-клавиатуры управляет различием между цифровым блоком и основными клавишами навигации. При `1` numpad-клавиши сохраняют собственные коды и могут бин-диться отдельно, при `0` они схлопываются к обычным стрелкам и Home/End/PgUp/PgDn. Переменная не помечена как `CVAR_ARCHIVE`; если значение должно переживать перезапуск, задавайте его через `seta` в своём конфиге.

#### Практические сценарии использования
```cfg
seta cl_keypad "1" // оставить отдельные бинды для клавиш numpad
```


Это может быть полезно для HUD/scoreboard-логики на сервере, но одновременно раскрывает лишнюю приватную информацию другим игрокам. #### Практические сценарии использования

