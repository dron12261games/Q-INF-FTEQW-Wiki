# Справочник переменных движка (cvar reference)

> [⬅ Вернуться к оглавлению вики](../README.md)

Этот раздел дополняет общую статью [«Настраиваемые переменные движка (cvar)»](../19-config-console/cvars-engine-variables.md) — там объясняется сам механизм cvar (что это такое, как задавать значения, разница между `set` и `seta`), а здесь собран предметный справочник по конкретным переменным движка FTEQW: что именно каждая из них делает, какие значения допустимы и как их применять на практике.

Переменных в движке — многие сотни. Справочник теперь охватывает практически все cvar, обнаруженные прямым поиском по исходному коду движка FTEQW (объявления `CVAR(...)`/`CVARD(...)`/`CVARF(...)`/`CVARFD(...)` и их варианты): более 1250 переменных суммарно по всем категориям. Для переменных без собственного комментария в коде движка в статье честно указано, что развёрнутого авторского описания нет, и приведено официальное краткое описание на английском (если оно есть в исходниках) либо контекст объявления.

## Как читать эти статьи

Каждая переменная описывается по единому шаблону: сигнатура вида `cvar имя_переменной(тип, значение_по_умолчанию)`, подробный разбор допустимых значений и крайних случаев, а также готовые к использованию примеры строк конфигурации или консольных команд.
