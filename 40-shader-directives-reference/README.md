# Справочник директив языка материалов (.shader)

> [⬅ Вернуться к оглавлению вики](../README.md)

Этот раздел дополняет статью [«Язык описания материалов (.shader)»](../08-materials-shaders/shader-script-language.md), где объясняется общая структура файла материала. Здесь собран построчный справочник по каждой отдельной директиве (ключевому слову), которую понимает парсер материалов FTEQW — как на уровне материала целиком, так и внутри отдельных стадий (`{ }`-блоков) материала.

## Категории

- [Директивы уровня материала (surfaceparm, cull, sort, deformVertexes и другие)](./01-shader-toplevel-directives.md)
- [Директивы уровня стадии (map, blendfunc, rgbGen, tcMod и другие)](./02-shader-stage-directives.md)

## Как читать эти статьи

Каждая директива описывается по единому шаблону: точный синтаксис на английском (как её нужно печатать в `.shader`-файле), разбор каждого параметра, подробное описание визуального эффекта и готовые к использованию примеры блоков материала.
