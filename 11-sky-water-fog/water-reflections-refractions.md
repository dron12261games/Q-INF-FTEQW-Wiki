# Вода с отражениями и преломлениями



> [⬅ Вернуться к оглавлению вики](../README.md)



> Раздел: [Небо, вода, туман](./README.md)



## Что это даёт геймдизайнеру



Поверхность воды (а также похожие жидкие поверхности — лава, слизь, телепортирующие текстуры) может быть не просто полупрозрачной текстурой, а полноценно отражать и преломлять то, что находится над и под её поверхностью — сцену за спиной игрока, стоящего у берега, или искажённый вид дна под водой. Это значительно усиливает ощущение достоверности и глубины водных поверхностей на уровне.



## Интерфейс настройки



Базовая прозрачность жидких поверхностей регулируется переменными, каждая для своего типа поверхности (тип определяется по имени текстуры: имя, начинающееся на `*lava`, `*slime` или `*tele`, использует свою переменную, а любое другое имя, начинающееся на `*` — обычную воду):



| Переменная | Назначение | Значение по умолчанию |

|---|---|---|

| [`r_wateralpha`](../38-cvars-reference/01-video-rendering-cvars.md#r_wateralpha) | прозрачность обычной воды (значение `1` — непрозрачная вода, меньшие значения делают её более прозрачной) | `1` |

| `r_lavaalpha` | прозрачность поверхности лавы (если оставлена пустой — берётся значение `r_wateralpha`) | пусто |

| `r_slimealpha` | прозрачность слизи (если оставлена пустой — берётся значение `r_wateralpha`) | пусто |

| `r_telealpha` | прозрачность телепортирующих поверхностей (если оставлена пустой — берётся значение `r_wateralpha`) | пусто |



Возможность видеть сквозь воду (в том числе смотреть на геометрию под водой из-под её поверхности) зависит от того, разрешена ли на сервере повышенная видимость воды — это контролируется серверной настройкой `watervis` (влияющей на клиентскую переменную `ruleset_allow_watervis`); на некоторых серверах со строгими правилами честной игры эта возможность может быть намеренно отключена, чтобы вода оставалась полностью непрозрачной и не давала игрокам увидеть то, что находится под ней. Если сервер вообще не транслирует ключ `watervis`, поведение определяется клиентским cvar `ruleset_allow_watervis` (по умолчанию `1`, то есть разрешено).



Движок автоматически генерирует материал для стандартных водных поверхностей карты (текстур с именами `*water...`, `*lava...`, `*slime...`, `*teleport...`), выбирая один из шести уровней визуального качества через переменные **[`r_waterstyle`](../38-cvars-reference/01-video-rendering-cvars.md#r_waterstyle)**, **`r_lavastyle`**, **`r_slimestyle`**, **`r_telestyle`** (каждая — для своего типа жидкости; если конкретная переменная не задана — используется значение `r_waterstyle`). Более продвинутые визуальные эффекты отражения и преломления самой поверхности воды (не только прозрачность, но и искажение вида, отражение окружения) можно также настроить вручную через собственный материал этой поверхности (см. [«Язык описания материалов»](../08-materials-shaders/shader-script-language.md)), используя специальные текстуры-подстановки `$reflection` (изображение сцены, отражённой от плоскости поверхности), `$refraction` (изображение сцены под поверхностью, видимое сквозь неё) и `$refractiondepth` (карта глубины преломлённой сцены, нужная шейдеру для эффекта Френеля и мягкого затухания на границе с берегом) — таким образом, автор мода может по-разному оформить, например, спокойное лесное озеро и бурлящую подземную реку, просто описав для них разные материалы.



## Инженерный справочник



#### Cvar



| Cvar | Сигнатура | Описание | По умолчанию |

| :--- | :--- | :--- | :--- |

| `r_waterstyle` | `r_waterstyle(int, "1")` | Выбирает уровень визуального качества автогенерируемого материала жидкости для водных поверхностей | `1` |

| `r_lavastyle` | `r_lavastyle(int, "1")` | Выбирает уровень визуального качества автогенерируемого материала жидкости для лавы | `1` |

| `r_slimestyle` | `r_slimestyle(string, "")` | Выбирает уровень визуального качества автогенерируемого материала жидкости для слизи; если переменная не задана, используется значение `r_waterstyle` | пусто |

| `r_telestyle` | `r_telestyle(int, "1")` | Выбирает уровень визуального качества автогенерируемого материала жидкости для телепортирующих поверхностей | `1` |

| `r_fastturb` | `r_fastturb(int, "0")` | Принудительно включает самый дешёвый стиль (`0`) для всех жидкостей независимо от значения `r_waterstyle` | `0` |



#### Директивы .shader/.particles



| Директива | Синтаксис | Описание |

| :--- | :--- | :--- |

| `ALPHA` | `ALPHA=<число>` | Явно переопределяет прозрачность конкретного материала воды, игнорируя `r_wateralpha`/`r_lavaalpha`/`r_slimealpha`/`r_telealpha` |



#### Другое



| Элемент | Синтаксис/тип | Описание |

| :--- | :--- | :--- |

| Стиль `-1` | — | Поверхность становится полностью невидимой (`nodraw`) — используется, если итоговая прозрачность (см. `ALPHA` выше) равна нулю |

| Стиль `0` | — | «Быстрый» режим (форсируется также переменной `r_fastturb`): поверхность закрашивается плоским цветом `r_fastturbcolour` без искажений и текстуры, максимальная производительность на слабом оборудовании |

| Стиль `1` | — | Классический режим «vanilla»: обычная текстура с волнообразным покачиванием текстурных координат (`tcmod turb`) и, если прозрачность меньше `1`, полупрозрачным смешиванием с фоном; это единственный режим, доступный без поддержки шейдерных программ |

| Стиль `2` | Требует framebuffer-объектов | Добавляет полноценное преломление (`$refraction`) сцены под поверхностью с эффектом Френеля (искажение сильнее под острым углом обзора) |

| Стиль `3` | Требует framebuffer-объектов | Преломление + полноценное зеркальное отражение окружения (`$reflection`) поверх преломлённого изображения |

| Стиль `4` | Требует framebuffer-объектов | Преломление с дополнительной картой ряби (`$ripplemap`), создающей неровности на границе преломления |

| Стиль `5` | Требует framebuffer-объектов (максимальное качество) | Комбинация отражения, преломления и карты ряби одновременно — самый дорогой по производительности, но самый реалистичный режим |

| `$reflection` | Спецтекстура внутри `map` | Отражённое от плоскости поверхности изображение сцены, доступное только внутри материалов, назначаемых на водные поверхности |

| `$refraction` | Спецтекстура внутри `map` | Изображение сцены под поверхностью воды, видимое сквозь неё с учётом преломления |

| `$refractiondepth` | Спецтекстура внутри `map` | Карта глубины преломлённой сцены — используется для затухания эффекта у берега и расчёта Френеля |



## Примеры



- Игрок, плавающий у поверхности спокойного озера, видит сквозь полупрозрачную воду песчаное дно благодаря включённой `watervis` и уменьшенному значению `r_wateralpha`.

- На соревновательном сервере с включёнными строгими правилами честной игры вода намеренно сделана полностью непрозрачной, чтобы никто не мог разглядеть противников, спрятавшихся под водой.

- На мощном ПК автор мода устанавливает `r_waterstyle 5`, включая одновременно отражения, преломление и рябь для максимально реалистичной воды в демонстрационном ролике, а на слабых системах игроки понижают значение до `1` или включают `r_fastturb 1` ради стабильного кадража.
