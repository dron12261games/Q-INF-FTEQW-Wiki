## Что это даёт геймдизайнеру

`.pk3` (и его менее распространённые «родственники» `.pk4`, `.pkz`, `.pkx`, `.iwd`, `.kpf`) — это обычный **ZIP-архив**, которому просто дали другое расширение файла. Формат появился вместе с Quake III Arena и с тех пор стал стандартом де-факто для множества движков этого семейства, включая FTEQW.

Преимущества перед старым форматом PAK:
- **Сжатие.** В отличие от PAK, файлы внутри ZIP-архива можно (хотя и не обязательно) сжимать, уменьшая итоговый размер дистрибутива мода.
- **Совместимость с обычными инструментами.** Архив можно открыть, посмотреть и отредактировать любым привычным ZIP-архиватором (7-Zip, WinRAR, стандартный «Проводник» Windows и т.д.) — не нужен специальный инструмент для игровых PAK-файлов.
- **Множественные архивы и приоритет.** В одну папку мода можно положить сразу несколько `.pk3`-файлов, и движок подключит их все, разрешая конфликты имён файлов по определённому правилу приоритета (см. ниже).

## Интерфейс настройки

1. Соберите нужные файлы мода в обычный ZIP-архив любым архиватором.
2. Переименуйте получившийся файл, дав ему расширение `.pk3` (самый распространённый и рекомендуемый вариант) вместо `.zip`.
3. Положите файл в папку основной игры ([`basegame`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#basegame)) или мода ([`gamedir`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir)) — движок подхватит его автоматически при следующем запуске или по команде [`fs_restart`](../44-cli-commands-reference/05-filesystem-system-commands.md#fs_restart).

**Приоритет между несколькими архивами.** Если один и тот же файл ресурса (например, текстура с одним и тем же именем) находится сразу в нескольких подключённых `.pk3`-архивах, движок выбирает архив по определённому правилу — обычно побеждает архив, чьё имя идёт **последним по алфавиту** (либо самый недавно изменённый — это регулируется переменной движка, отвечающей за приоритизацию пакетов). Это удобно использовать намеренно: например, называть свои патчи/дополнения так, чтобы они алфавитно шли позже основного архива мода, и тем самым гарантированно его переопределяли.

**Дополнительно поддерживаемые ZIP-подобные расширения** (для совместимости с другими движками и играми): `.pk4` (Quake 4), `.pkz` (q2pro), `.pkx` (q2xp — забавный исторический казус: другой похожий порт, yq2, при этом использует обычный `.pk3`, то есть единого стандарта расширения для ZIP-архивов в этом семействе движков так и не сложилось), `.iwd` (Call of Duty 2), `.apk` (стандартный формат установочных пакетов Android), `.kpf` (обычный ZIP-архив, который распознаётся, но не сканируется автоматически при старте — такой архив нужно подключать явно, что предотвращает случайное превращение произвольного стороннего ZIP-файла, оказавшегося в папке игры, в игровой архив). Все они, кроме `.kpf`, обрабатываются движком одинаково и автоматически, как обычный ZIP-архив, — разница только в расширении файла.

---

## Инженерный справочник: поддерживаемые ZIP-подобные расширения

| Расширение | Происхождение | Автоматическое сканирование при старте |
| :--- | :--- | :--- |
| `.pk3` | Родное расширение Quake III Arena, стандарт де-факто для FTEQW | да |
| `.pk4` | Quake 4 | да |
| `.pkz` | Порт q2pro | да |
| `.pkx` | Порт q2xp | да |
| `.iwd` | Call of Duty 2 | да |
| `.apk` | Установочный пакет Android | нет (обрабатывается отдельно на уровне платформы) |
| `.kpf` | Обычный ZIP-архив без автоматического распознавания | нет, требует явного подключения |

---

## Примеры

- Мод для Quake, распространяемый как один файл `mymod.pk3`, внутри которого лежит вся стандартная структура папок (`maps/`, `models/`, `sounds/`, `progs.dat` и т.д.), как если бы это была обычная файловая система.
- Небольшой архив-патч `zzz_hotfix.pk3`, который алфавитно идёт после основного архива мода и содержит только несколько исправленных файлов — так удобно выпускать точечные исправления, не пересобирая весь мод заново.
- Разработчик, портирующий контент из мода для другого движка семейства id Tech, обнаруживает архив с расширением `.iwd` или `.pkz` — благодаря общей поддержке ZIP-подобных контейнеров такой архив можно просто переименовать в `.pk3` (или оставить как есть) и сразу подключить к FTEQW без перепаковки содержимого.
