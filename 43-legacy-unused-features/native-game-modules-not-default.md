# Совместимость с игровыми модулями Quake III / Half-Life

> [⬅ Предыдущая страница](deprecated-and-stub-builtins.md) | [Следующая страница ➡](halflife-model-format-caveats.md)

> [⬅ Вернуться к оглавлению вики](../README.md)

Это устаревший путь совместимости для запуска чужих, нативных (то есть скомпилированных под конкретную операционную систему, а не в виде переносимого QuakeC-байт-кода) игровых модулей, а не основной способ разработки мода под FTEQW.

## Что включено по умолчанию, а что нет

- В стандартной конфигурации FTEQW включены подсистемы совместимости **Quake II** (`Q2SERVER`) и **Quake III** (`Q3SERVER`/`Q3CLIENT`).
- Поддержка **Half-Life / GoldSrc** в той же конфигурации **выключена по умолчанию**: опции `HLSERVER` и `HLCLIENT` закомментированы.
- Даже там, где подсистема совместимости собрана, загрузка **нативного** игрового кода из игровой папки дополнительно блокируется переменной [`com_gamedirnativecode 0`](../38-cvars-reference/04-network-server-cvars.md#com_gamedirnativecode) ради безопасности.

---

## Практические последствия

- **Quake II**-модуль может быть подхвачен как родная библиотека игры; движок ищет совместимые имена вроде `game*.dll`/`.so`, включая старый `gamex86.dll`.
- **Quake III**-совместимые VM/модули зависят от конкретной подсистемы и платформы: это уже не обычный QuakeC-путь, а отдельный слой совместимости.
- **Half-Life**-модули требуют специальной сборки движка; при её наличии движок ориентируется на `liblist.gam` и имя `gamedll`, указанное в моде.

---

## Ограничения и риски

- Такой код выполняется как обычная нативная библиотека ОС, **без песочницы**.
- Совместимость сильно зависит от разрядности процесса, платформы и от того, под какой ABI/версии API собран сам модуль.
- Для обычной вики и для повседневной разработки лучше считать этот путь исключением, а не нормой.

---

## Что использовать вместо этого

Если мод должен запускаться на типовых сборках FTEQW без специальных оговорок, ориентируйтесь прежде всего на [SSQC](../16-quakec-scripting/server-side-quakec-ssqc.md), [CSQC](../16-quakec-scripting/client-side-quakec-csqc.md) и [Q1QVM](../17-alternative-scripting-vms/q1qvm-bytecode.md).
