# Устаревшие, экспериментальные и недоступные по умолчанию возможности

> [⬅ Вернуться к оглавлению вики](../README.md)

## Зачем нужен этот раздел

В коде движка FTEQW встречается немало возможностей, которые формально существуют, но на практике не стоит на них полагаться при создании игры или мода: часть из них требует пересборки движка из исходного кода с нестандартными настройками (то есть недоступна в готовых, распространяемых сборках движка), часть — экспериментальна и может вести себя непредсказуемо в зависимости от платформы и видеодрайверов, а часть — попросту устарела и вытеснена более новыми, удобными механизмами. Здесь собраны все такие случаи с объяснением, что именно не работает «из коробки» и почему, чтобы не тратить время на отладку того, что физически не может заработать в обычной сборке движка.
