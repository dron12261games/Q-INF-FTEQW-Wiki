# Файлы перевода интерфейса

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Локализация и переводы](./README.md)

## Что это даёт геймдизайнеру

Позволяет выпустить игру или мод сразу для аудитории, говорящей на разных языках, не создавая под каждый язык отдельную сборку и не дублируя игровую логику. Все текстовые фразы (сообщения, названия предметов, реплики персонажей, пункты меню) хранятся в игровой логике под неизменными идентификаторами на английском языке, а конкретный переведённый текст для каждого языка подгружается движком отдельно, из внешних файлов перевода — точно так же, как это устроено в профессиональных переводах программ (используется распространённый в индустрии формат файлов перевода `.po`, тот же, что применяется, например, в Linux-приложениях).

## Интерфейс настройки

Игрок выбирает используемый язык переменной **`lang`** (например, `lang "ru"` для русского, `lang "en"` для английского) — значение состоит из кода языка и, при необходимости, региона (`ru_RU`) или кодировки. Движок сам подбирает наиболее подходящий доступный файл перевода по этому коду, с постепенным упрощением (сначала ищется точное совпадение языка и региона, затем — только языка), и всегда имеет запасной вариант перевода на английском, если для указанного языка перевода не нашлось.

Сами переводы хранятся в текстовых файлах:

- основной способ — файлы формата `.po` внутри папки **`localisation/`** (обратите внимание — именно британское написание слова, с «s», а не с «z») игры или мода, с именем, соответствующим коду языка (например, `localisation/ru.po`); внутри такого файла каждая фраза записывается парой строк `msgid "исходная фраза"` / `msgstr "переведённая фраза"` — этот же формат используют многие профессиональные переводческие инструменты, что позволяет привлекать переводчиков, знакомых со стандартными программами локализации, без специального обучения;
- дополнительно поддерживается более простой построчный формат **`localization/loc_<язык>.txt`** (здесь же папка называется уже по-американски, через «z» — это две разные, независимо проверяемые папки), совместимый с обновлённым переизданием Quake, для случаев, когда нужно использовать уже готовые переводы из того переиздания; оба источника перевода (`.po` и `loc_*.txt`) могут применяться одновременно — движок объединяет обе таблицы переводов для выбранного языка.

Игровой сценарий получает переведённую строку по её исходному (обычно английскому) тексту или идентификатору — движок сам подставляет вместо неё соответствующий перевод из активного языка. Благодаря этому автору мода достаточно один раз написать всю игровую логику и текст на одном языке, а переводчики затем просто заполняют файлы перевода, не трогая саму логику игры. Автоматический перевод применяется движком к целому ряду стандартных серверных сообщений «из коробки» — например, к тексту всплывающих диалоговых окон (prompt), сообщениям по центру экрана (centerprint) и названиям карт/режимов игры в списке серверов — то есть даже без специального обращения к переводу из самой игровой логики часть текста уже переводится автоматически по правилам, встроенным в движок.

## Примеры

- Мод поставляется с файлами `localisation/ru.po`, `localisation/de.po` и `localisation/fr.po` — при первом запуске в системе с русской локалью игра автоматически подхватывает `lang "ru"` и показывает переведённый интерфейс.
- Переводчик, незнакомый с внутренним устройством мода, получает лишь файл `.po` и с помощью стандартной программы для переводчиков (умеющей открывать этот формат) переводит все фразы игры, не имея доступа к самой игровой логике.
