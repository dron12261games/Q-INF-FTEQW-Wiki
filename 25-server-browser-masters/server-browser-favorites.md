## Что это даёт геймдизайнеру

Игроку не нужно вручную помнить IP-адреса серверов, на которых можно поиграть в конкретный мод, — движок умеет автоматически получать актуальный список публично доступных серверов через специальные «мастер-серверы» (централизованные каталоги активных серверов) и показывать их в удобном списке прямо в меню. Понравившиеся серверы можно сохранить в личный список избранного, чтобы быстро возвращаться к ним снова, не разыскивая их заново каждый раз в общем списке.

---

## Интерфейс настройки

Со стороны сервера видимость в общем списке контролируется переменной **[`sv_public`](../38-cvars-reference/04-network-server-cvars.md#sv_public)**:

| Значение | Поведение |
|---|---|
| `-1` | полностью блокирует все входящие подключения (сервер недоступен вообще) |
| `0` | сервер не публикуется на мастер-серверах — подходит для приватных игр в локальной сети |
| `1` | сервер публикуется на публичных мастер-серверах, его адрес виден всем — требует правильно настроенного роутера, разрешающего входящие подключения |
| `2` | сервер публикуется через сервер-посредник с поддержкой автоматического обхода домашнего роутера (см. [«Помощь в прямом соединении между игроками (ICE/STUN/TURN)»](../28-nat-traversal/ice-stun-turn-p2p.md)) — то есть даже без ручной настройки переадресации портов сервер всё равно можно будет найти и подключиться к нему |

С клиентской стороны список серверов обновляется командами **[`globalservers`](../44-cli-commands-reference/02-client-ui-commands.md#globalservers)** (запросить список у мастер-серверов в интернете) и **[`localservers`](../44-cli-commands-reference/02-client-ui-commands.md#localservers)** (см. [«Поиск серверов в локальной сети (LAN)»](./lan-discovery.md)). Список избранных серверов игрок формирует прямо из интерфейса браузера серверов (отмечая понравившиеся серверы «в избранное»), а сохраняется этот список автоматически в текстовый файл **`favourites.txt`** — при желании его можно отредактировать и вручную, добавив нужные серверы по имени и адресу напрямую в текст файла.

---

## Примеры

- Игрок открывает встроенный браузер серверов, видит список активных публичных серверов интересующего его мода и подключается к одному из них одним щелчком.
- Постоянный игрок отмечает свой любимый сервер как избранный — движок сохраняет его в `favourites.txt`, и с этого момента сервер всегда легко найти в начале списка при следующем запуске игры.
