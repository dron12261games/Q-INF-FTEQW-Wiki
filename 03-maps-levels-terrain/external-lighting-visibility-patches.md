# Внешние патчи освещения и видимости (.lit/.hdr/.lux/.vis)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Уровни, карты и ландшафт](./README.md)

## Что это даёт геймдизайнеру

Освещение и видимость карты можно частично доработать отдельными файлами-спутниками, не перекраивая сам `.bsp`. На практике в коде подтверждены три разные линии поддержки: цветное освещение (`.lit`/`.hdr`), направленное освещение (`.lux`, плюс совместимый вариант `.dlit`) и внешние патчи видимости (`.vis`) для Quake-подобных BSP.

## Интерфейс настройки

- **`.lit`** — внешнее цветное освещение стандартного диапазона.
- **`.hdr`** — тот же принцип, но с HDR-представлением освещения.
- **`.lux`** — внешние deluxemap-данные с направлением света; дополнительно понимается и старый алиас `.dlit`.
- **`.vis`** — внешний патч видимости для Quake-подобных карт; используется отдельно от `.lit`-линии и управляется другим cvar'ом.

Для `.lit`/`.hdr`/`.lux` основной переключатель — **`r_loadlit`**: `0` отключает внешнюю догрузку, `1` просто загружает найденные файлы, `2` разрешает автогенерацию отсутствующего LDR-освещения, `3` — HDR-варианта. Если внешний файл найден и валиден, он используется первым; BSPX-данные внутри самого `.bsp` выступают как fallback, а не как приоритетная замена внешнему файлу.

Для `.vis` используется **`mod_external_vis`**. Поддержка реально есть, но она относится именно к Quake-подобным BSP и принимает отдельный patch-файл только из того же gamedir, что и карта; это сделано как совместимый путь для исправления PVS/прозрачной воды и похожих старых проблем.

## Инженерный справочник

#### Cvar

| Cvar | Сигнатура | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `r_loadlit` | `r_loadlit(int, "1")` | Управляет загрузкой/автогенерацией `.lit`/`.hdr`/`.lux` | `1` |
| `mod_external_vis` | `mod_external_vis(int, "1")` | Разрешает загрузку внешних `.vis`-патчей для Quake-подобных карт | `1` |

#### Другое

| Элемент | Синтаксис/тип | Описание |
| :--- | :--- | :--- |
| `.lit` | `QLIT` v1 | Цветное LDR-освещение; существует и расширенный `QLIT` v2, но он прямо помечен как нестандартизованный/неустоявшийся вариант |
| `.hdr` | `QLIT` HDR-вариант | HDR-освещение в packed `E5BGR9`-представлении |
| `.lux` / `.dlit` | deluxemap-данные | Направление света для каждого luxel'я |
| `.vis` | patch-файл для Quake BSP | Внешняя поправка данных видимости/leaf-таблиц |

## Примеры

- Старая карта получает цветной пересчёт через `.lit`, не требуя перекомпиляции всей геометрии.
- Карта с выраженным normal-mapped освещением использует `.lux`, чтобы рельефные материалы реагировали на направление света правдоподобнее.
- Автор классической Quake-карты оставляет `mod_external_vis 1`, чтобы движок подхватил внешний `.vis`-патч для прозрачной воды и исправленной видимости.
