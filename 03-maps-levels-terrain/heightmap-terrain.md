# Ландшафт на основе карт высот (heightmap terrain)

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Уровни, карты и ландшафт](./README.md)

## Что это даёт геймдизайнеру

Помимо привычных «коробочных» уровней из BSP-геометрии, движок поддерживает отдельный тип уровня — ландшафт на основе **карты высот** (heightmap): большое открытое пространство, форма которого задаётся не вручную вылепленной геометрией, а простой сеткой значений высоты, разбитой на плитки-тайлы с собственными текстурами. Это отлично подходит для крупных открытых пространств, гор, холмистой местности — того, что было бы крайне трудоёмко строить вручную в виде классической геометрии.

## Интерфейс настройки

Основной собственный формат этой подсистемы — **`.hmp`**. Команда `map` также умеет принимать `.map`/`.map.gz` как editor-friendly вариант уровня, а часть редакторских команд работает и с таким представлением, но именно стандартный путь создания/сохранения terrain-мира в этой подсистеме — `maps/имя.hmp`.

### Пошаговый туториал: создание пустого ландшафта

**Шаг 1.** Выполните в консоли команду создания нового пустого ландшафта:

```
mod_terrain_create mymap "Долина ветров" terrsky1 ground1_1 -1024 *water2 0
```

**Шаг 2.** Движок сгенерирует файл `maps/mymap.hmp` с базовым описанием мира — единственной точкой старта игрока в центре и настройками ландшафта по умолчанию.

**Шаг 3.** Загрузите получившийся ландшафт как обычную карту: `map mymap`.

**Шаг 4.** Редактируйте форму и текстуры ландшафта прямо во время игры специальным редакторским инструментом (требуется дополнительный клиентский аддон редактирования, `csaddon.dat`), и сохраняйте изменения командой `mod_terrain_save`.

### Ключи сущности `worldspawn`, управляющие ландшафтом

Помимо самого файла ландшафта, поведение и внешний вид всего уровня определяется набором специальных ключей сущности `worldspawn`, автоматически создаваемых при генерации нового ландшафта (их также можно вручную редактировать в текстовом виде):

| Ключ | Тип данных / формат | Назначение | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `_sky` | строка, имя набора текстур неба | Название используемого скайбокса/панорамы неба над ландшафтом | `terrsky1` |
| `_fog` | число с плавающей точкой | Плотность атмосферного тумана над поверхностью ландшафта | `0.02` |
| `_maxdrawdist` | число, игровые единицы | Принудительная максимальная дальность прорисовки, переопределяющая дальность тумана, если она больше | `0` (не задано) |
| `_segmentsize` | целое число, игровые единицы | Размер одной секции (тайла) ландшафта — влияет на текстурирование и итоговое разрешение детализации | `1024` |
| `_minxsegment` / `_minysegment` | целые числа, игровые единицы | Минимальные X/Y-координаты, ограничивающие область ландшафта | `-2048` |
| `_maxxsegment` / `_maxysegment` | целые числа, игровые единицы | Максимальные X/Y-координаты, ограничивающие область ландшафта | `2048` |
| `_seed` | строка | Зерно генерации для плагинов процедурной автогенерации рельефа | пусто |
| `_exterior` | строка (`solid`/иное) | Тип содержимого за пределами явно созданных секций ландшафта (по умолчанию — сплошная твёрдая материя, чтобы игрок не мог провалиться за край мира) | `solid` |
| `_defaultgroundtexture` | строка, имя текстуры/материала | Текстура грунта по умолчанию для ещё не отредактированных участков ландшафта | `ground1_1` |
| `_defaultgroundheight` | число, игровые единицы | Высота грунта по умолчанию для ещё не отредактированных участков | `-1024` |
| `_defaultwatertexture` | строка, имя текстуры/материала | Материал воды по умолчанию (например, для областей ниже уровня моря) | `*water2` |
| `_defaultwaterheight` | число, игровые единицы | Уровень «моря» по умолчанию | `0` |

### Полезные консольные команды для работы с ландшафтом

Полезные консольные команды для работы с ландшафтом (в первую очередь предназначенные для авторов уровней и администраторов, дорабатывающих ландшафт прямо во время игры):

| Команда | Синтаксис | Назначение |
|---|---|---|
| `mod_terrain_create` | `mod_terrain_create ИМЯ "ОПИСАНИЕ" НЕБО ГРУНТ ВЫСОТА_ГРУНТА ВОДА ВЫСОТА_ВОДЫ [зерно]` | создать новый пустой ландшафт с указанными параметрами по умолчанию, сохранённый в `maps/ИМЯ.hmp` |
| `mod_terrain_save` | `mod_terrain_save` | сохранить текущее состояние ландшафта на диск |
| `mod_terrain_reload` | `mod_terrain_reload` | перезагрузить ландшафт с диска, отменив несохранённые изменения |
| `mod_terrain_convert` | `mod_terrain_convert [имякарты] [текстура-для-удаления]` | преобразовать ландшафт в актуальный вариант формата, при необходимости выборочно — только определённые тайлы по имени текстуры (медленная операция) |

Внутренне ландшафт делится на **sections** по 16×16 тайлов; каждая секция хранит сетку высот 17×17 сэмплов (с перекрытием по краю), а на диске секции дополнительно группируются в более крупные block-файлы. Это полезно помнить при оценке детализации, culling и сетевой догрузки.

## Примеры

- Открытая карта для командного режима строится как единый крупный ландшафт с холмами и оврагами, вместо тысяч вручную расставленных геометрических блоков.
- Автор мода донастраивает существующий ландшафт прямо во время тестовой игры и сохраняет изменения командой `mod_terrain_save`, не выходя в отдельный редактор.
- Уровень с процедурно генерируемым рельефом использует ключ `_seed` в `worldspawn`, чтобы одно и то же зерно давало один и тот же ландшафт для всех игроков сессии.
