# Карты Half-Life 2 и поддержка через плагины

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Уровни, карты и ландшафт](./README.md)

## Что это даёт геймдизайнеру

Помимо форматов, которые движок понимает «из коробки», часть более сложной и специфичной поддержки других игровых экосистем (в частности, работа с играми на основе Half-Life 2) реализована через отдельно подключаемые модули расширения — [«Модули расширения движка (плагины)»](../35-engine-plugins/engine-plugin-modules.md). Это позволяет не раздувать размер базовой поставки движка ради поддержки редко используемых или юридически чувствительных форматов, но при этом всё равно предоставлять к ним доступ тем, кому это действительно нужно.

## Интерфейс настройки

Поддержка запускается через файл-манифест (см. [«Файл-манифест мода»](../23-mods-manifests/mod-manifest-file.md)) или напрямую консольной командой подключения нужного модуля (`plug_load`). Для игр на основе Half-Life 2 движок сам предлагает готовый профиль запуска с параметром командной строки **`-halflife2`** (или `-gmod9` для отдельного профиля, ориентированного на надстройку GMod 9) — при этом типе запуска движок автоматически ищет характерный для этой игровой экосистемы файл описания игры **`gameinfo.txt`** внутри игровой папки (`hl2/gameinfo.txt` или `gmod9/gameinfo.txt` соответственно) и, обнаружив его, выполняет заранее подготовленную встроенную конфигурационную команду, автоматически подгружающую физический модуль **ODE** и специализированный модуль совместимости под именем **`hl2`** (два последовательных вызова `plug_load ode` и `plug_load hl2`). Дополнительно этот профиль запуска ссылается на готовый набор загружаемых пакетов расширения — модуль видео/аудио на основе FFmpeg, модуль физики ODE и сам модуль совместимости Half-Life 2 — которые при необходимости могут быть автоматически загружены с сервера пакетов движка. Для геймдизайнера это означает, что достаточно запустить движок с указанием соответствующего профиля игры (`-halflife2` или `-gmod9`) и положить игровые файлы этой экосистемы в ожидаемую структуру папок — совместимость подключится сама, без ручной настройки списка модулей.

## Инженерный справочник

#### Параметры командной строки

|     Параметр     | Аргумент | Описание |
| :--- | :--- | :--- |
| `-halflife2` | — | Выбирает готовый профиль игры «Rad-Therapy-II», ищущий `hl2/gameinfo.txt` и загружающий модули совместимости |
| `-gmod9` | — | Отдельный готовый профиль игры для надстройки GMod 9 поверх Half-Life 2, ищущий `gmod9/gameinfo.txt` |

#### Команды консоли

| Команда | Аргументы | Описание |
| :--- | :--- | :--- |
| `plug_load` | `ode` | Загружает модуль расширения физики ODE (выполняется автоматически при определении игры) |
| `plug_load` | `hl2` | Загружает модуль совместимости с форматами и логикой Half-Life 2 (включая карты) (выполняется автоматически при определении игры) |

#### Другое

| Элемент | Синтаксис/тип | Описание |
| :--- | :--- | :--- |
| `hl2/gameinfo.txt` / `gmod9/gameinfo.txt` | Путь к файлу-маркеру | Признак, по которому движок опознаёт, что в данной игровой папке лежит контент именно этой экосистемы |
| `fteplug_hl2` | Имя загружаемого пакета расширения | Собственно модуль поддержки карт/форматов Half-Life 2 (подгружается с сервера пакетов при необходимости) |
| `fteplug_ode` | Имя загружаемого пакета расширения | Модуль физики ODE (подгружается с сервера пакетов при необходимости) |
| `fteplug_ffmpeg` | Имя загружаемого пакета расширения | Модуль видео/аудио декодирования на основе FFmpeg (подгружается с сервера пакетов при необходимости) |

## Примеры

- Мод для игры на основе Half-Life 2 запускается параметром `-halflife2`, движок находит `hl2/gameinfo.txt` и сам подгружает модули `ode` и `hl2`.
- Сборка, ориентированная на контент надстройки GMod 9, запускается параметром `-gmod9` вместо `-halflife2`, используя отдельный, специально подготовленный под эту надстройку профиль обнаружения игры.
- Разработчик, распространяющий сборку с нестандартной поддержкой карт, включает загрузку нужного модуля прямо в свой файл-манифест, чтобы это происходило автоматически при первом запуске, без необходимости указывать особый параметр командной строки.
