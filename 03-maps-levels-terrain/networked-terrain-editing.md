# Совместное редактирование ландшафта в реальном времени

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Уровни, карты и ландшафт](./README.md)

## Что это даёт геймдизайнеру

Ландшафт на основе карты высот (см. [«Ландшафт на основе карт высот»](./heightmap-terrain.md)) можно редактировать не только в одиночку в редакторе, а **прямо во время игры на сервере, совместно с другими подключёнными игроками** — правки сервера автоматически рассылаются всем клиентам в реальном времени, а недостающие участки ландшафта клиенты докачивают по мере необходимости. Это открывает необычные сценарии: совместное строительство ландшафта несколькими людьми одновременно, интерактивные миры, меняющиеся прямо по ходу игры, или инструменты для быстрого прототипирования уровня всей командой сразу.

## Интерфейс настройки

Совместное редактирование включается серверной переменной **`mod_terrain_networked`**: если она включена, любые изменения ландшафта (форма поверхности, типы текстур на тайлах, расстановка объектов на нём) автоматически пересылаются по сети всем подключённым клиентам, а клиенты, которым не хватает каких-то участков ландшафта, докачивают их у сервера по мере надобности, без необходимости заранее иметь полную карту целиком у себя на диске.

## Инженерный справочник: связанные переменные ландшафта

| Cvar | Тип данных | Описание | Значение по умолчанию |
| :--- | :--- | :--- | :--- |
| `mod_terrain_networked` | булево (0/1) | Включает сетевую синхронизацию правок ландшафта: клиенты докачивают секции по требованию, а сервер уведомляет клиентов об изменениях | `0` |
| `mod_terrain_defaulttexture` | строка, имя текстуры | Текстура, назначаемая заново создаваемым тайлам ландшафта; как правило, обновляется самим редактором ландшафта, а не вручную | пусто |
| `mod_terrain_savever` | строка | Версия внутреннего формата секции ландшафта, используемая при сохранении отредактированных данных на диск | пусто (текущая версия) |
| `mod_terrain_sundir` | вектор `x y z` | Направление условного «солнца», используемое при просчёте статичного освещения ландшафта (вектор автоматически нормализуется) | `0.4 0.7 2` |
| `mod_terrain_ambient` | число с плавающей точкой | Доля рассеянного (ambient) света в общей формуле освещения ландшафта | `0.5` |
| `mod_terrain_shadows` | булево (0/1) | Включает трассировку лучей для определения затенённых участков ландшафта | `0` |
| `mod_terrain_shadow_dist` | число, игровые единицы | Максимальная дальность трассировки лучей при поиске перекрывающей свет геометрии для теней | `2048` |
| `mod_map_lights` | булево (0/1) | Просчитывает освещение на обычных геометрических кистях/патчах ландшафтной карты | `0` |
| `mod_map_texscale` | число с плавающей точкой | Масштаб текселей текстуры на геометрии карты: `1` для карт Quake/Quake II, `0.5` для карт формата Quake III | `1` |

## Примеры

- На сервере с включённым `mod_terrain_networked` несколько администраторов одновременно правят форму ландшафта, и изменения сразу видны всем подключённым игрокам.
- Экспериментальный мультиплеерный «песочница»-режим позволяет игрокам совместно перестраивать ландшафт прямо во время матча.
- Автор карты включает `mod_terrain_shadows 1` и подбирает направление `mod_terrain_sundir`, чтобы статичные тени от рельефа ложились в нужную сторону перед финальным сохранением ландшафта.
