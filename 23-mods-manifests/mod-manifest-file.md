## Что это даёт геймдизайнеру

Манифест — это один небольшой текстовый файл с расширением **`.fmf`**, который полностью описывает вашу игру или мод: как её называть, откуда брать данные, где искать обновления и недостающие файлы, какие настройки применить по умолчанию. Манифест решает главную проблему самостоятельных проектов на основе движка: как чётко «отделить» свою игру от Quake и от других модов, чтобы у игроков не путались конфигурации, сохранения и списки серверов, и чтобы игру можно было запустить одним двойным щелчком, без разбора параметров командной строки.

Манифест особенно полезен для:
- **полностью самостоятельных игр** (standalone) на движке — тех, что не хотят иметь ничего общего с Quake;
- **модов с автообновлением** — таких, что сами докачивают новые версии файлов, не заставляя пользователя переустанавливать всё вручную;
- **сборок нескольких модов**, где не все файлы должны скачиваться заранее.

## Интерфейс настройки

Манифест — это простой текстовый файл `name.fmf`, где каждая строка — это отдельная команда. Строки начинающиеся с `//` — комментарии.

```
FTEMANIFEST 1
GAME quake
NAME "In The Shadows"
PROTOCOLNAME ITShadows
BASEGAME id1
BASEGAME qw
GAMEDIR shadows
-seta cl_forwardspeed 400
+bind w +forward
```

Способы запуска манифеста:
- **двойной щелчок** по `.fmf`-файлу (если движок зарегистрирован как обработчик такого типа файлов в системе);
- файл **`default.fmf`**, лежащий рядом с движком (в папке, указанной параметром [`-basedir`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#basedir)) — движок подхватит его автоматически при старте и полностью возьмёт на себя определение того, какая это игра, без собственного «угадывания»;
- консольная команда **[`gamedir modname`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir)** — загружает файл `modname.fmf` из текущей базовой папки;
- на Android — открытие `.fmf`-файла предлагает запустить его через приложение движка, как на обычном ПК;
- в веб-версии (WebGL) — имя манифеста указывается прямо в адресной строке браузера после символа `#`.

Основные команды внутри самого `.fmf`-файла:

| Команда | Назначение |
|---|---|
| `FTEMANIFEST 1` | обязательная первая строка, версия формата манифеста |
| `GAME <name>` | кодовое имя игры ([`quake`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#quake), [`quake2`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#quake2), [`quake3`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#quake3), [`hexen2`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#hexen2) — для известных игр подтягивают разумные настройки по умолчанию; для самостоятельной игры выбирается любое своё имя) |
| `NAME "Full Game Name"` | как игра будет отображаться в текстовых сообщениях |
| `PROTOCOLNAME "name"` | уникальный идентификатор для списков серверов — чтобы игроки других игр не видели ваши сервера и наоборот |
| `BASEGAME "folder"` | базовая папка с данными, всегда подключаемая (можно указать несколько; более поздние имеют приоритет) |
| `GAMEDIR "folder"` | папка мода — в отличие от [`BASEGAME`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#basegame), заменяется целиком при смене мода командой [`gamedir`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir) |
| `DISABLEHOMEDIR 1` | не использовать домашнюю папку пользователя для хранения конфигов/сохранений (для «переносных» игр, устанавливаемых вручную) |
| `MAINCONFIG "file.cfg"` | имя основного конфигурационного файла — позволяет изолировать конфиги мода от конфигов других движков/модов, работающих с той же папкой данных |
| `-set name value` | команда, выполняемая ДО стандартного `default.cfg` мода — переопределяет базовые настройки движка, не ломая сам мод |
| `+set name value` | команда, выполняемая ПОСЛЕ `default.cfg` — «дожимает» финальные настройки поверх всего |
| `MINVER FTE <number>` / `MAXVER FTE <number>` | требования к минимальной/максимальной версии движка, при которых манифест ещё будет использоваться |
| `EULA "text or path"` | лицензионное соглашение, которое движок покажет пользователю перед первым запуском игры/мода — используется для юридически значимых уведомлений. |
| `ICON "path.png"` | относительный путь к файлу-иконке (обычно PNG), которую движок использует для отображения игры в собственных списках и ярлыках. |
| `UPDATEURL "address"` | адрес, откуда сам движок (а не только данные игры) может проверить и скачать более новую версию себя самого для этой конкретной игры/мода. |
| `SCHEMES "name1 name2 ..."` | список URI-схем (например, для протокола `steam://` или собственной схемы игры), под которые движок должен зарегистрировать себя в операционной системе как обработчик по умолчанию. |
| `DEFAULTEXEC "command"` | команда, добавляемая в список выполняемых при старте, аналогично `-set`/`-bind`, но заданная одной строкой напрямую. |

### Специальный синтаксис путей в `BASEGAME`/`GAMEDIR`

Помимо простого имени папки, значение `BASEGAME`/`GAMEDIR` поддерживает несколько особых префиксов:
- **`*name`** — помечает папку как «приватную» (см. ниже, данные не видны другим клиентам/движкам в списках серверов); одинокая звёздочка `*` без имени означает «искать пакеты прямо в базовой папке движка», что используется для совместимости с некоторыми не-Quake играми.
- **`/name`** — помечает папку особым флагом совместимости («qshack»), используемым для специфичных корректировок поведения при чтении такой папки.
- **`steam:subfolder/modname`** — особый синтаксис, указывающий движку найти игру, установленную через Steam, и подключить конкретную подпапку внутри неё как игровые данные — удобно для модов, требующих файлы лицензионной игры, уже стоящей у пользователя через Steam, без необходимости вручную объяснять игроку, куда её устанавливать.

Полезные консольные команды для работы с манифестами:
- [`fs_showmanifest`](../44-cli-commands-reference/05-filesystem-system-commands.md#fs_showmanifest) — показать манифест, действующий прямо сейчас;
- [`fs_changegame <name>`](../44-cli-commands-reference/05-filesystem-system-commands.md#fs_changegame) — переключиться на другую известную игру (или манифест по ссылке/пути), при необходимости запросив у пользователя, где искать её файлы.

Если у папки в `BASEGAME`/`GAMEDIR` в начале имени стоит звёздочка (`*fte`) — это «приватная» папка, данные из которой не сообщаются в списки серверов и не видны клиентам других движков (полезно для настроек, специфичных именно для этого движка).

## Примеры

- Полностью самостоятельная игра поставляется с файлом `default.fmf`, который задаёт `GAME mygame`, `NAME "My Standalone Game"`, `PROTOCOLNAME MSG1` и отключает домашнюю папку — так игра ведёт себя как обособленный продукт, никак не пересекаясь с Quake.
- Мод для классического Quake переопределяет пару стандартных настроек управления через `+bind`/`+set`, не трогая исходный `default.cfg` игры, — используя манифест как «патч» поверх основной игры.
- Компиляция нескольких модов организована так, что каждый мод описан своим `.fmf`, и игрок переключается между ними командой [`gamedir`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir), не переустанавливая движок заново.
