# Переключение между установленными модами

## Что это даёт геймдизайнеру

Игрок и сервер могут переключаться между разными модами и играми **без перезапуска самого движка** — простой командой в консоли. Это удобно и для игроков (быстро попробовать другой мод), и для проектов, объединяющих несколько игр/модов «под одной крышей» одного движка.

---

## Интерфейс настройки

Основная команда — **[`gamedir <name>`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir)**:

- движок ищет файл `<name>.fmf` (см. [«Файл-манифест мода»](./mod-manifest-file.md)) в текущей базовой папке и, если находит, полностью загружает описанный в нём мод/игру — переключая набор игровых папок, конфигов и настроек;
- если такого `.fmf`-файла нет, движок пробует загрузить `default.fmf` из той же папки, а если и его нет — пытается сам угадать, какая игра установлена в текущей папке данных, и подставляет туда указанное имя как папку мода.

Аналогичный эффект получается при запуске движка с параметром командной строки [`-game <name>`](../44-cli-commands-reference/01-fteqw-startup-parameters.md#game) (см. [«Параметры запуска игры»](../19-config-console/startup-parameters.md)) — только это происходит один раз при старте, а не «на лету» из консоли.

Для полной смены самой игры (не мода поверх той же игры, а перехода к принципиально другой игре — например, с Quake на Quake II) служит команда **[`fs_changegame <name>`](../44-cli-commands-reference/05-filesystem-system-commands.md#fs_changegame)**. Она распознаёт короткие имена известных игр движка и пытается переключить базовую папку данных на неё (при необходимости — спросив у игрока, где эта игра установлена, либо найдя её автоматически по данным, оставленным официальным установщиком этой игры). Если указанное имя не относится к известной движку игре, оно воспринимается как путь или ссылка на произвольный файл-манифест.

Посмотреть, какой манифест действует прямо сейчас, можно командой [`fs_showmanifest`](../44-cli-commands-reference/05-filesystem-system-commands.md#fs_showmanifest).

---

## Примеры

- На сервере, где по очереди проводятся турниры по разным модам, администратор переключает конфигурацию одной командой [`gamedir capturetheflag`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir), не перезапуская сам процесс сервера.
- Игрок, установивший рядом несколько тотальных конверсий на одном движке, выбирает нужную через [`gamedir <name>`](../44-cli-commands-reference/04-server-multiplayer-commands.md#gamedir) прямо из меню консоли, не разбираясь с ярлыками и параметрами командной строки.
- Обладатель уже установленной легальной копии Quake II запускает основанный на движке мод для неё командой [`fs_changegame quake2`](../44-cli-commands-reference/05-filesystem-system-commands.md#fs_changegame), и движок сам находит нужную папку с игровыми данными.
