# Автоматическая докачка недостающих файлов мода

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Моды, сборки и манифесты](./README.md)

## Что это даёт геймдизайнеру

Эта возможность позволяет модам и играм **не включать все файлы данных в установщик заранее**, а вместо этого докачивать их автоматически с сервера, когда они реально понадобились игроку. Это удобно для:

- сборок и модов, использующих контент других игр (когда нельзя распространять сами файлы из-за авторских прав, но можно скачать их только у тех, у кого уже есть легальная копия);
- модов с частыми обновлениями — не нужно пересобирать и заново распространять весь установщик целиком;
- масштабных проектов, где полный набор файлов слишком велик, чтобы включать его в базовую установку.

## Интерфейс настройки

Список загружаемых файлов описывается прямо в [файле-манифесте](./mod-manifest-file.md) (`.fmf`) с помощью команд:

```
PACKAGE "id1/pak0.pak" 0x4f069cac "http://mirror1.example.com/qsw106_pak0.pak" "http://mirror2.example.com/qsw106_pak0.pak"
ARCHIVEDPACKAGE "id1/pak0.pak" 0x4f069cac "id1/pak0.pak" "http://mirror1.example.com/qsw106.zip"
DOWNLOADSURL "https://updates.triptohell.info/downloadables.php?game=Q1"
INSTALL "package1;package2"
```

- **`PACKAGE`** — указывает «логическое имя» файла (путь внутри игровой папки), контрольную сумму (CRC) его содержимого и один или несколько адресов-зеркал, откуда его можно скачать. Движок сам случайным образом выбирает зеркало (для равномерной нагрузки) и пробует следующее, если предыдущее не сработало. Файлы с разными CRC могут сосуществовать как разные версии одновременно.
- **`ARCHIVEDPACKAGE`** — то же самое, но когда по ссылке лежит не сам файл, а zip-архив с установочными файлами, из которого нужно достать один конкретный файл. Это удобно для повторного использования уже готовых установочных архивов от сторонних источников, которые ничего не знают про манифесты.
- **`DOWNLOADSURL`** — адрес, откуда движок может получить список необязательных дополнительных пакетов, которые игрок сам решает ставить или нет.
- **`INSTALL`** — список файлов, которые «настоятельно рекомендуется» поставить: игроку будет предложено это сделать, если их не хватает, но решение всегда остаётся за игроком.
- Контрольная сумма (CRC) может быть указана как `-`, если её не хотят проверять вовсе — но это не рекомендуется, так как отключает всякую защиту от повреждённых или подменённых файлов.

Если у игрока уже есть файл с таким именем (например, ранее установленная игра), докачка не будет выполнена повторно даже при несовпадении контрольной суммы — считается, что это осознанный выбор игрока. Скачанные файлы сохраняются в специальную папку кэша загрузок (`dlcache`) с постфиксом по контрольной сумме, что позволяет разным версиям одного и того же файла существовать одновременно, не конфликтуя друг с другом.

### Докачка недостающих файлов прямо с игрового сервера

Помимо манифеста, у движка есть отдельный, более «классический» механизм: если при подключении к серверу выясняется, что у клиента не хватает какого-то файла (например, карты, модели или клиентской логики CSQC), сервер может сам предложить клиенту скачать этот файл напрямую с себя или с указанного URL. Этим механизмом на стороне клиента управляет отдельный набор переменных:

| Переменная | По умолчанию | Назначение |
| :--- | :--- | :--- |
| `cl_downloads` | `1` | Общий выключатель — при `0` полностью блокирует любые автоматические докачки файлов с сервера. |
| `cl_download_csprogs` | `1` | Разрешает докачивать обновлённую клиентскую игровую логику (CSQC, `csprogs.dat`), если сервер предлагает более новую версию. |
| `cl_download_redirection` | `2` | Разрешает серверу перенаправить докачку на внешний адрес вместо себя самого: `0` — запрещено, `1` — разрешено на любой адрес (потенциально небезопасно, сервер может указать почти произвольную команду), `2` — разрешено только на прямые ссылки на пакеты и демозаписи (более безопасный режим, включён по умолчанию). |
| `cl_download_packages` | `1` | Что делать с целыми пакетами (архивами) данных, которые использует сервер: `0` — не скачивать вовсе, `1` — скачать и подключить только на время игры на этом сервере, `2` — скачать и установить насовсем (использовать с осторожностью — постоянно устанавливает контент с недоверенного сервера). |
| `cl_download_wait` (старое имя `requiredownloads`) | `1` | `1` — дождаться завершения всех докачек перед входом в игру; `0` — зайти в игру сразу, не дожидаясь докачки (возможны видимые дефекты, пока файлы ещё скачиваются). |
| `cl_download_mapsrc` | пусто | Отдельный адрес-префикс (например, `https://maps.example.com/`), откуда клиент попробует скачать недостающий файл карты, если сервер использует карту, которой у игрока ещё нет — типичный сценарий для серверов с постоянно меняющимся пулом пользовательских карт. |

## Примеры

- Мод для Quake не включает в свой установщик файлы оригинальной игры (защищённые авторским правом), а лишь описывает в манифесте, где их можно докачать тем, у кого их ещё нет.
- Крупный контент-пак с картами распространяется не единым большим установщиком, а как набор отдельных `pk3`-пакетов, каждый из которых регистрируется отдельной строкой `PACKAGE` — так игрок скачивает только то, что реально нужно.
