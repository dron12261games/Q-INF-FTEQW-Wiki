# Запечённые карты освещения и стили освещения

> [⬅ Вернуться к оглавлению вики](../README.md)

> Раздел: [Освещение и тени](./README.md)

## Что это даёт геймдизайнеру

Классический подход к освещению уровня — заранее просчитать, как свет ложится на каждую поверхность карты, и сохранить результат прямо в саму карту в виде **карты освещения** (lightmap). Это быстрый и надёжный способ получить качественное, реалистично выглядящее статичное освещение, не требующий вычислительных мощностей во время самой игры. Дополнительно движок поддерживает **стили освещения** — способ анимировать яркость уже запечённого света без пересчёта самой карты: мерцание факела, мигающая неисправная лампа, или свет, который выключается и включается по игровому событию.

## Интерфейс настройки

Сама карта освещения рассчитывается заранее утилитой компиляции уровня и хранится внутри `.bsp`-файла карты (либо в отдельном файле — см. [«Внешние патчи освещения и видимости»](../03-maps-levels-terrain/external-lighting-visibility-patches.md)); отдельная настройка со стороны геймдизайнера для самого запекания не требуется — она входит в процесс сборки карты.

**Стиль освещения** назначается конкретному источнику света на карте (обычному статичному светильнику) через встроенную функцию QuakeC **[`lightstyle`](../37-quakec-builtins-reference/08-csqc-rendering-builtins.md#lightstyle)** (стандартная встроенная функция движка номер 35, вызывается из программного кода игры, а не из консоли):

```
lightstyle(имя_стиля, "строка_анимации", [необязательный вектор цвета r g b])
```

Строка анимации — это последовательность букв от `a` (свет полностью выключен) до `z` (свет горит на полную яркость), где каждая буква — это один «кадр» анимации, проигрываемый друг за другом по кругу. Например, строка `"mmnmmommommnonmmonqnmmo"` создаёт эффект мерцающего пламени, а `"a"` — полностью выключенный свет, `"z"` — ровный постоянный свет на максимальной яркости. Свет с одним и тем же номером стиля на карте меняет яркость синхронно, что позволяет управлять сразу целой группой светильников одной командой из игровой логики (например, выключить всё освещение в комнате при срабатывании ловушки). Необязательный третий аргумент — вектор RGB-цвета — позволяет дополнительно перекрасить все источники света с этим номером стиля в произвольный цвет, а не только менять их яркость.

Скорость и плавность анимации стилей можно дополнительно донастроить со стороны игрока переменными `r_lightstylespeed` (скорость смены кадров анимации, число кадров в секунду, по умолчанию `10`) и `r_lightstylesmooth` (булево 0/1, плавное перетекание яркости между кадрами вместо резких скачков, по умолчанию `0` — отключено).

## Инженерный справочник

#### Встроенные функции QuakeC

| Функция | Сигнатура | Описание |
| :--- | :--- | :--- |
| `lightstyle` | `void(float lightstyle, string stylestring, optional vector rgb) lightstyle = #35;` | Задаёт анимацию яркости (и опционально цвет) для всех источников света с указанным номером стиля на текущей карте |

#### Cvar

| Cvar | Сигнатура | Описание | По умолчанию |
| :--- | :--- | :--- | :--- |
| `r_lightstylespeed` | `r_lightstylespeed(float, "10")` | Скорость проигрывания кадров строки анимации стиля (кадров в секунду) | `10` |
| `r_lightstylesmooth` | `r_lightstylesmooth(int, "0")` | Включает плавную интерполяцию яркости между соседними кадрами анимации вместо резкого переключения | `0` |
| `r_lightstylesmooth_limit` | `r_lightstylesmooth_limit(int, "2")` | Максимальная разница между соседними кадрами (в буквенных шагах), при превышении которой плавная интерполяция отключается и происходит резкий скачок (чтобы, например, резкое выключение света не «размазывалось» по времени) | `2` |

## Примеры

- Факелы на стенах уровня используют мерцающий стиль освещения, придающий им живой, неровный свет пламени.
- При активации сигнализации игровая логика меняет стиль освещения аварийных ламп на «мигающий» через `lightstyle`, создавая эффект тревоги во всей комнате одновременно.
